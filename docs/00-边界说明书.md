# 玖白（Chiubay）边界说明书

> **文档地位**：本项目最高约束文件，先于架构、代码、课程与评估。任何与本文冲突的设计以本文为准。
> 版本：v0.2 | 2026-11-26
> 适用：本机阶段（机制验证）+ 单机规模阶段（100M-1B）
> 关系：`DEVELOPMENT.md` v0.3 中与本文件冲突的条目（PyTorch、gymnasium、<1M 上限、无序列模块）以本文件为准，待基础方案定稿后统一重写。
> 本版关键变更：锁定“单人全栈自研”，删除外部算力/团队路线，新增诚实边界条款。

---

## 1. 北极星与交付分层

### 1.1 目标定义

项目采用如下 AGI 定义作为方向引用：

> 具备与人类相当或超越人类的广泛认知能力、能像人一样学习并完成几乎任何智力任务的人工智能系统。

### 1.2 必须先承认的四件事

1. 该定义没有公认的量化阈值。本项目自行给出操作化指标（§8），并声明这是**本项目口径**，不是学术界共识。
2. 本机（Apple M5 Max / 128 GiB / 单机）**无法训练人级基座**：算力与前沿规模相差 8-10 个数量级。
3. **单人 + 全栈自研 + 本机**三者叠加后，执行层（Metal 内核、张量引擎）也由一人完成；不做多机分布式，没有团队、没有集群、没有外部算力。
4. 因此本项目定位为**长期个人研究计划**：AGI 是方向，不是交付承诺；单机天花板约 1B 参数（极限 3B），不构成人级基座。

### 1.3 交付分层

| 层 | 时间 | 环境 | 参数规模 | 交付物 | 能否验证 AGI 定义 |
|---|---|---|---|---|---|
| **L 层：机制验证** | 0-12 月 | 本机 CPU（NumPy 辅助） | <10M | 自研栈 + LSE + 发育阶段 S0-S2 | 不能，只验证“像人一样学习”的机制 |
| **S 层：单机规模扩展** | 12 月-数年 | 本机 Metal（自写内核） | 100M-1B（极限 3B） | S3-S5 部分能力 + 单机规模律 | 不能完整验证，只覆盖部分能力 |
| **S6：开放世界** | — | — | — | **明确不做** | 不能 |

**判定**：L 层是机制证明；S 层是单机规模证明；S6 超出单人单机范围。任何一层都不得宣称“达成 AGI”。

## 2. 约束分层

### 2.1 不可让渡（hard）

| ID | 约束 | 含义 |
|---|---|---|
| H1 | 人级 AGI 为方向 | 长期方向，不作为本阶段交付承诺；不降级为“架构验证项目”的宣传口径 |
| H2 | 全栈自研 | 架构、学习规则、训练循环、评估、张量引擎、算子、Metal 内核、序列模块全部自研 |
| H3 | 无预训练 | Child 不加载任何预训练权重，不蒸馏现成模型参数 |
| H4 | 本机单人 | 不接外部集群、不组队、不外包核心工程；L/S 层均在本机完成 |
| H5 | 可复现 | 固定 seed / 配置 / 父母模型 snapshot，结果可重跑 |
| H6 | 诚实标注 | 不得宣称达成 AGI；能力缺口公开；不得用提示词或现成模型伪装能力 |

### 2.2 可调整（soft）

| ID | 约束 | 调整条件 |
|---|---|---|
| S1 | L 层参数上限 | 1M 可审批放宽至 10M，需说明架构必要性 |
| S2 | 阶段周期 | 按实际吞吐重估，不按愿望排期 |
| S3 | Parents 后端 | API 为主；预算与 snapshot 策略可调 |
| S4 | 沙盒形态 | 自研 GridWorld 起步；S 层可加自研 3D 简化物理 |
| S5 | 序列模块形态 | 自研 recurrent / 轻量注意力 / 混合，按消融结果定 |

### 2.3 冲突裁决顺序

```text
H3 无预训练 > H2 全栈自研 > H6 诚实标注 > H4 本机单人 > H1 方向 > soft 可调项
```

即：**诚实高于目标**。当目标不可达时，如实标注，不用话术弥补。

## 3. 自研边界

### 3.1 四层划分

| 层 | 内容 | 归属 | 本项目例子 |
|---|---|---|---|
| 智能机制 | 架构、学习规则、路由、扩展、评估 | **必须自研** | LSE、门控、联动桥、分裂/合并、发育评估 |
| 执行层 | 张量抽象、自动微分、算子、优化器、内核、训练调度 | **必须自研** | 自写 Tensor、手动梯度、Metal 着色器 |
| 数学底层 | BLAS、Metal 驱动与编译器 | 基础设施例外（§3.2） | Apple Accelerate / Metal |
| 基础设施 | OS、语言运行时、HTTP、绘图 | 允许使用 | macOS、Python 3.13、httpx、matplotlib |

### 3.2 白名单 / 黑名单与例外

**允许**：

- Python 标准库、`httpx`/`requests`、`json`/`csv`、`matplotlib`
- NumPy：仅用于内存块、索引、形状操作、逐元素运算
- BLAS / Metal 驱动与编译器：视为 CPU/GPU 指令集级基础设施

**禁止（Child 代码路径）**：

- `torch`、`tensorflow`、`jax`、`transformers`、`sklearn`
- `gymnasium` 及任何现成 RL 框架
- 任何预训练权重、任何现成 MoE / Transformer 实现
- 任何自动微分库（梯度必须自写或采用自研学习规则）
- 任何现成分布式训练框架

**必须自写**：张量类、计算图/梯度、矩阵乘调度、Softmax、LayerNorm、Adam、Metal 内核、checkpoint、课程采样器、评估器。

**基础设施例外说明**：

- 矩阵乘的底层 BLAS 调用视为硬件基础设施，不算“智能机制”。
- 若要求连 BLAS 也自研，L 层吞吐将下降 100 倍以上，项目不可行。
- 该例外必须记录在 `docs/adr-001-blas-exception.md`，任何扩大解释需书面批准。

**父母例外**：Parents 按定义就是现成大模型，允许 API；但不得把父母参数复制、蒸馏或初始化进 Child。

### 3.3 合规检测

- CI 静态扫描 `src/child/` 与 `src/runtime/` 的 import，命中黑名单直接失败。
- Child 路径禁止通用权重加载函数；只允许加载本项目自产 checkpoint。
- 每次实验在 `runs/<exp>/deps.json` 记录依赖清单与版本。
- 代码审查必查：是否存在“先用现成模型跑通再改写”的偷渡路径。
- 每月人工抽查一次：随机选 3 个核心算子，确认非库调用。

### 3.4 执行层路线（已决策 D1）

**决策：不借用任何 ML 框架；S 层自写 Metal 内核；单节点；不做多机分布式。**

| 工作项 | 工程量估算 | 风险 |
|---|---|---|
| Metal matmul / softmax / layernorm / Adam | 6-12 个月 | 着色器正确性与数值稳定性 |
| 激活值分块、checkpoint、内存规划 | 2-4 个月 | 128 GiB 上限下的 OOM |
| 单机 1B 训练（1-2B token/run） | 2 周-3 个月/run | 吞吐不足导致周期失控 |
| 3B 训练（8-bit optimizer + 梯度检查点） | 边缘可行 | 内存与热量 |
| 多机分布式 | **不做** | 超出单人范围 |

**若未来要突破 1B，只能修改 H4（组队/外部算力），不得修改 H2。** 修改 H4 等于重启项目形态，需重新立项。

## 4. AGI 能力差距

| AGI 要求 | 当前 LSE | 缺口 | 本项目覆盖 |
|---|---|---|---|
| 广泛认知能力 | 单一 GridWorld | 任务域覆盖、跨域迁移 | 部分（S1-S5） |
| 像人一样学习 | 离线策略梯度 | 持续学习、少样本、无灾难遗忘 | 可验证（S3-S4） |
| 几乎任何智力任务 | 无语言、无记忆、无工具 | 序列、长时记忆、世界模型、工具 | **不可验证** |
| 自主性 | 无 | 目标自设、课程自生成 | 可验证（S5） |
| 自我改进 | 有分裂/合并接口，未验证 | 自我修改的安全闭环 | 可验证（S5） |
| 社会性 | 无 | 他者建模、合作、价值内化 | 部分（S3） |
| 规模广度 | 单机 1B 上限 | 人级基座需 100B+ | **超出范围** |

**结论**：本项目能验证“成长机制”，不能验证“广泛智力”。语言与记忆必须在 L 层正面设计，否则 S2 直接卡死；但即使全部通过，也不等于 AGI。

## 5. 发育阶段与交付物

| 阶段 | 名称 | 核心能力 | 课程 | 退场条件 | 所属层 |

## 6. 量化边界

### 6.1 L 层（本机 CPU）

| 项 | 预算 |
|---|---|
| 参数量 | <1M（默认），最多 10M（审批） |
| 环境步数 | 10^7-10^8 |
| 自研栈吞吐目标 | ≥200 steps/s（batch 64） |
| 单次实验时长 | 1-24 小时 |
| 内存 | <8 GiB（Child + 环境 + 日志） |
| 并行实验 | 1-2 个，避免互相拖慢 |

### 6.2 S 层（本机 Metal）

| 项 | 预算 |
|---|---|
| 参数量 | 100M-1B 常规；3B 极限 |
| 训练 token | 1B-2B / run |
| 训练算力 | 10^19-10^20 FLOPs / run |
| 单次训练时长 | 2 周-3 个月 |
| 硬件 | 本机 M5 Max / 128 GiB |
| 预算 | API <$50/月 + 电费 |
| 多机 | 不做 |

**数量级对照**：人级基座需 10^24-10^26 FLOPs，本层差 4-6 个数量级。这不是优化问题，是物理边界。

## 7. 明确不做 / 做不到

| 项 | 判定 | 理由 |
|---|---|---|
| 单人实现人级 AGI | 做不到 | 全栈自研 + 单机 + 单人，三重限制 |
| 本机产出人级基座 | 做不到 | 算力差 8-10 个数量级 |
| 本机训练 100B | 做不到 | 内存与算力双重不足 |
| 多机分布式自研 | 超出范围 | 需团队与集群；单人不可维护 |
| 不用任何已知数学/语言/OS | 做不到，也不必要 | 连算术都无法进行；自研指不调用现成智能实现 |
| 完全脱离 MoE/注意力等已知概念 | 做不到 | 概念可以借鉴，实现必须自研；禁止照搬代码与权重 |
| 12 个月内达成 AGI | 做不到 | L 层机制验证都需 6-12 月 |
| 用 API 父母替代规模数据与算力 | 做不到 | 父母只提供信号，不提供参数与算力 |
| 用“小模型 + 提示词”冒充 AGI | 禁止 | 违反 H1/H3/H6，验收时直接否决 |

## 8. 验收口径

### G0：机制门（S0 结束）

| 指标 | 阈值 |
|---|---|
| 自研合规 | Child/执行层黑名单 import = 0；无预训练权重 |
| 专家激活熵（归一化） | 0.40-0.80，且训练前后显著下降 |
| 专家-状态互信息 | >0.10 bit，优于随机路由基线 |
| 路由一致性 | 同一状态重复前向，Top-K 专家重合率 >70% |
| 吞吐 | ≥200 steps/s |
| 可复现 | 5 seeds，IQM reward 的 95% CI 不与随机策略重叠 |

### G1：语言门（S2 结束）

| 指标 | 阈值 |
|---|---|
| 未见指令组合准确率 | >80% |
| 序列模块消融 | 移除后准确率下降 >20%，证明模块有效 |
| 持续学习 | 学新任务后旧任务下降 <10% |
| 符号接地 | 同一词在不同场景指向同一概念，人工抽检 >80% |

### G2：自改门（S5 结束）

| 指标 | 阈值 |
|---|---|
| 影子副本修改成功率 | >50%（通过 Guardian 测试且能力不降） |
| 回滚可恢复率 | 100% |
| 审计完整率 | 100% |
| 修改后能力 | 目标任务不下降，至少一项新任务提升 |

### G3：单机规模门（S 层）

| 指标 | 阈值 |
|---|---|
| 参数量 | ≥100M，目标 1B |
| 任务域 | ≥3 个自研域 |
| 留出泛化 | 未见任务显著优于同规模自研 baseline（预注册协议） |
| 训练可复现 | 2 seeds；单次 ≤3 个月 |
| 自研合规 | 黑名单 import = 0；Metal 内核自写率 100% |

## 9. 风险登记与 kill criteria

| 风险 | 概率 | 影响 | 应对 | Kill 条件 |
|---|---|---|---|---|
| Metal 内核延期 | 高 | S 层无法启动 | 先 CPU 验证算子，再逐个移植 | 12 个月无可用 matmul |
| 自研栈吞吐不足 | 高 | 实验周期失控 | 向量化、C 扩展（仍自研） | 优化后 <50 steps/s |
| 单机训练时间过长 | 高 | 迭代停滞 | 缩模型/缩 token/课程分批 | 单次训练 >6 个月 |
| 专家始终不分化 | 中 | 架构假设不成立 | 调温度、多样性损失、改路由 | 9 个月 G0 未过 |
| 语言模块无法接地 | 中 | S2 卡死 | 换序列形态、改课程 | G1 两次重试未过 |
| API 成本/漂移 | 中 | 不可复现、超预算 | snapshot、缓存、预算上限 | 月成本超 $50 |
| 自我修改失控 | 低 | 安全事件 | 影子副本、kill switch | 出现未授权合并 |
| 单人维护崩溃 | 高 | 项目停摆 | 极简栈、文档、每周复盘 | 连续 3 个月无有效进展 |

**冻结不等于失败**：若 S 层无法启动，项目应发布 L 层机制结果，并明确声明“未达成 AGI 定义”，不得包装。

## 11. 变更控制

1. 本文件每次变更需：版本号 + 理由 + 影响范围 + 受影响的阶段门。
2. Hard constraints（§2.1）变更需单独书面决定，不得在代码或配置中静默绕过。
3. 与 `DEVELOPMENT.md` 冲突时以本文件为准；基础方案定稿后，`DEVELOPMENT.md` 重写为 v1.0 并删除与自研约束冲突的 PyTorch/gymnasium 内容。
