## 2. 验收结果

### 2.1 单元测试

```text
Ran 10 tests in 0.238s
OK
```

覆盖：add 广播、matmul、softmax、sigmoid/tanh/relu、reshape/transpose、mean/sum、XOR、吞吐、合规、checkpoint。梯度校验容差 `atol=1e-6, rtol=1e-5`（float64）。

### 2.2 XOR 训练

```text
epoch=   0 loss=0.258182
epoch= 500 loss=0.000108
epoch=1000 loss=0.000033
epoch=1500 loss=0.000016
epoch=2000 loss=0.000009
epoch=2500 loss=0.000006

loss=0.000004 accuracy=100%
steps/s=18590.6  elapsed=0.16s
```

- 结构：2 → 8（Sigmoid）→ 1（Sigmoid）
- 优化器：Adam，lr=0.05，3000 epochs，全批量 4 样本
- 结论：自研张量栈可从随机初始化学会非线性任务。

### 2.3 吞吐

- 测试模型：64 → 64（ReLU）→ 10，batch 64
- 实测：约 1.8×10⁴ steps/s（小模型，不含环境步进）
- 注意：这不是 G0 的口径。G0 要求 LSE + 沙盒 ≥200 steps/s；LSE 有 Top-K 路由与联动桥，实际会低一个量级，需在 M2 重测。

### 2.4 合规

- `src/` 全量 AST 扫描：黑名单 import = 0。
- 无预训练权重；checkpoint 仅本项目自产。
- BLAS 例外记录于 `docs/adr/ADR-001-blas-exception.md`。

## 3. 已知限制

| 限制 | 影响 | 计划 |
|---|---|---|
| 仅支持 2D/批量 matmul | 复杂结构需更多形状算子 | M1 按需补 |
| 反向传播为闭包实现 | 图较大时 Python 开销高 | M2 视吞吐优化，必要时 C 扩展 |
| 未实现 LayerNorm / Embedding / Attention | LSE 联动桥与语言模块需要 | M1/M3 补 |
| 未实现 Top-K 路由 | LSE 核心未开始 | M1 |
| 无环境步进 | 吞吐数字偏乐观 | M2 加 GridWorld 后重测 |
