## 0. 为什么先谈标准，不谈方案

你说"任何后续做法在方案不完善时，都是盖在一个错误地基之上"。这句话是对的，
而且它要求的第一件事不是"想出更多创新点"，是**先定义什么叫创新合格**。
否则我每写一版都能自称创新，你无法判断，我也无法自证。

同时必须说明："每一处都创新"按字面有三个不可解的问题：

| 问题 | 说明 |
|---|---|
| **不可验证** | 创新是相对基线说的。若每个部件都新，就没有基线，无法归因。实验做出来，不知道是谁的功劳。 |
| **无限回溯** | 张量运算、浮点格式、语言运行时、文件系统——若都要求新，项目十年跑不起第一行。这与"本机培养智能"直接冲突。 |
| **创新≠有效** | 全新的部件可能只是不同，不是更好。没有对照的创新是信仰，不是工程。 |

因此本文做一次转换：

> **把"每一处都创新"翻译成"没有一处是未经审计的借用"。**

后者可执行、可证伪、可被第三方审查。它比前者更严：前者的反例是
"这看起来像已知方法"，后者的反例是"你填不出与已知方法的机制差别"。

## 1. 创新合格的四栏标准（Difference Audit）

每个部件（一个类、一条规则、一个指标）必须填满四栏。**任一栏为空即不合格。**

| 栏 | 要求 | 不合格的典型写法 |
|---|---|---|
| **N** 最近邻 | 最接近的已知方法，必须具名（作者+年份） | "无"、"这是新的" |
| **D** 机制差别 | 差在**机制**上，不是差在参数、规模、命名上 | "我们用了不同的激活函数" |
| **M** 可测后果 | 哪个实验能显示这个差别；差别测不出时会怎样 | "效果更好" |
| **A** 消融 | 去掉它，什么指标会变 | "影响不大" |

**判定规则：**

- N 空 → 说谎，不是创新。
- D 填不出机制差别 → **该部件是常规件**，必须标注 `CONVENTIONAL`，
  并说明为何允许它存在（通常是基础设施）。
- M 填不出 → 该差别不可观测，等于没有差别 → 删。
- A 做出来无变化 → 该部件是装饰 → 删。

这条标准把"创新"从形容词变成了**可驳回的声明**。

因为承认它之前，任何新方案都只是给旧方案换名字。

`CONVENTIONAL`，**不参与任何创新声明**，也不出现在报告的创新章节里。

## 3. 第一性原理检查（生成创新的方法）

审计只能删，不能生。生成要靠一个具体方法，不是靠"多想"。

**对每个功能问三遍：**

1. **如果我不知道任何神经网络，我会怎么让一个系统具备这个功能？**
   例：要让系统"记住刚才发生了什么"——神经网络给的答案是 RNN；
   不知道 RNN 的人会想到"让状态自己慢慢衰减/累积"，也就是物理上的
   惯性或弛豫。两个答案不同，后者才是本项目的候选。

2. **这个功能在生物体里由什么承担？不是"哪个脑区"，是"什么物理过程"。**
   例：记忆不是"存起来的向量"，是**突触的持续可塑性状态**——
   它是结构的一部分，不是数据。这直接否定"记忆模块"这种设计。

3. **如果把这个功能写成一条物理定律，它会是什么形式？**
   例：稳态 = 负反馈；发育 = 在应力集中处长出材料；学习 = 弛豫到更低能量。

**三问都答完，才允许写公式。** 三问中若有一问的答案与某个已知 ML 技术
一模一样，就承认它是常规件，不要包装。

## 4. 重构后的地基：三个"取消"

前两版方案的问题是：都在**保留 MDP 框架**的前提下做文章
（观测→决策→动作→奖励）。只要这个框架还在，做出来的东西一定能被
某个 RL 算法覆盖，创新就只能是局部的。

所以新地基是三个取消。它们不是改进，是**换掉前提**。

### 4.1 取消一：没有 (观测, 动作, 奖励) 三元组

**现状**：所有主流系统都是 `o_t → a_t → r_t`。RL 需要 (S,A,R)；
监督学习需要 (x,y)；LLM 需要 (context, next token)。三者都是
"输入—输出对"的不同形态。

**取消后**：系统与环境是**两个耦合的动力系统**，之间没有"接口"。

```
环境 E 的状态 e，系统 S 的状态 x，同一时间轴上共同演化：

  x_{t+1} = F( x_t ,  λ · A(e_t) )       A = 传入通道（环境扰动系统）
  e_{t+1} = G( e_t ,  μ · B(x_t) )       B = 传出通道（环境读取系统）

λ, μ 是固定的耦合强度，不学习。
```

这里没有"观测向量"，只有**环境对系统的一部分细胞的物理扰动**；
没有"动作集合"，只有**环境读取系统的一部分活动并据此改变自己**；
没有"奖励"，因为**没有任何东西在评价系统**。

**这就是 BCI 的功能结构**：BCI 不"告诉"大脑什么，它读神经活动、
写电刺激。项目借用的是这个**读写耦合**的结构，不是电极。

**与已知方法的精确差别（N/D 栏）：**

| 栏 | 内容 |
|---|---|
| **N** | 动力系统取向的认知科学（Beer 1995；Thelen & Smith 1994）；形态计算（Pfeifer & Bongard 2006） |
| **D** | 它们描述现象、建小规模模型；本项目的差别是**把读写耦合作为唯一接口，并据此取消策略与奖励**，让"任务"这个词在系统内不存在 |
| **M** | 如果接口真的取消了，那么**任何需要 (S,A,R) 的算法都无法直接套用**。可测：尝试用 REINFORCE 训练会失败，因为不存在 `π(a|s)` |
| **A** | 对照：把读写通道换成显式 obs/action 接口，同样结构下行为是否变差 |

**必须诚实**：这不是认知科学的新发现，动力学取向已有三十年历史。
本项目的差别只在**工程归属**——把接口取消当作硬约束，而不是当作隐喻。

**代价（必须写进风险）：** 没有动作集合，就没有"成功率"这种指标。
评估要换成"存活/稳态/耦合结构"，这是一个全新的评估体系，工作量巨大。

### 4.2 取消二：没有训练，只有发育

**现状**：训练 = 固定结构 + 反复更新参数 + 一条 loss 曲线。

**取消后**：结构本身在变。三种事件，全部由**局部量**触发：

| 事件 | 触发条件 | 做什么 | 不许用什么 |
|---|---|---|---|
| **分裂** | 某处局部预测误差持续高于邻域 | 该细胞一分为二，共享连接 + 微扰，互相抑制 | 不许用全局 loss 或适应度 |
| **修剪** | 某细胞长期活动低于阈值 | 移除，连接回收 | 不许用权重幅值排序（那是常规剪枝） |
| **迁移** | 活动梯度持续同向 | 细胞沿梯度缓慢移动，改变连接拓扑 | 不许用反向传播算梯度（用局部活动差） |

**"学习曲线"变成"生长曲线"**：横轴是时间，纵轴是细胞数、连接数、
分裂/修剪次数。参数更新只是副产品。

**与已知方法的精确差别：**

| 栏 | 内容 |
|---|---|
| **N** | NEAT（Stanley 2002，结构进化）；发育机器人学（Lungarella 2003）；自组织映射（Kohonen） |
| **D** | NEAT 用**全局适应度**选择拓扑；发育机器人学通常仍有人工设计的发育阶段。本项目：**触发信号只有局部预测误差，无适应度、无阶段表** |
| **M** | 若触发真是局部的，则在**没有任务**的环境里也应当发生分裂与修剪。可测：给一个纯随机扰动的环境（无任何任务），结构仍应发育；NEAT 在此环境下无法定义适应度 |
| **A** | 关掉分裂（固定结构），同样训练量下性能是否停滞 |

**这条最重要**：它让"没有全局损失"从口号变成结构事实——
没有适应度，就无法做进化选择；没有 loss，就无法做梯度下降。
两者都被结构性排除了。

### 4.3 取消三：没有教学，只有环境塑形

**现状**：示范、奖励塑形、课程标签、指令——都属于"把知识传给孩子"。

**取消后**：父母只做一件事：**改变环境的结构**。

| 父母做 | 父母不做 |
|---|---|
| 把物体放在孩子当前能力可及的位置 | 不给示范动作 |
| 造出有规律可循的空间（重复的几何） | 不给奖励或惩罚 |
| 逐步扩大可及范围 | 不给课程标签、不给指令 |
| 在孩子卡住时改变环境，而不是改变孩子 | 不纠正孩子的动作 |

**这不是"更好的教学法"，是取消教学这个概念。** 差别在：
示范会引入"复制"问题（孩子可能学会父母的错误）；环境塑形不传递任何
具体行为，只传递**世界的统计结构**。

**与已知方法的精确差别：**

| 栏 | 内容 |
|---|---|
| **N** | 课程学习（Bengio 2009）；环境设计；脚手架理论（Wood/Bruner 1976，心理学） |
| **D** | 课程学习调整**任务难度序列**，仍是任务；脚手架理论是心理学描述。本项目：父母的操作对象是**环境的物理结构**，且孩子端不存在"任务"这一概念 |
| **M** | 若父母只塑形不教学，则**父母无法把任何具体行为传给孩子**。可测：把父母换成随机塑形（无目的），孩子的最终结构复杂度应当接近——因为它学的是环境统计，不是父母意图 |
| **A** | 对照：示范式父母 vs 塑形式父母，孩子的行为多样性（不是成功率） |

**这条的可证伪性最强**：如果塑形式父母养出的孩子，行为和示范式父母
养出的高度相似，说明"环境塑形"实际上还是在传递行为，机制描述不实。

## 5. 三个取消之后，剩下什么

```
┌──────────────────────────────────────────────────┐
│              细胞群（唯一有状态的东西）              │
│  每个细胞：分室、局部预测、局部可塑性、位置           │
│  结构：会分裂、会修剪、会迁移                        │
└───────────┬──────────────────────┬───────────────┘
            │ 传入通道（被扰动）      │ 传出通道（被读取）
            ▼                      ▼
┌──────────────────────────────────────────────────┐
│           环境（物理结构，无任务、无奖励）           │
│  父母通过改变它的结构来"养育"                        │
└──────────────────────────────────────────────────┘
```

**系统中不存在的东西**（这是设计的核心，不是遗漏）：

- 不存在 loss 函数
- 不存在奖励
- 不存在动作集合
- 不存在策略
- 不存在任务
- 不存在训练/测试划分

**存在的只有**：细胞的局部预测、局部可塑性、结构事件、与环境的两条通道。

## 6. 我不打算假装创新的部分（诚实清单）

以下部分**保持常规**，并明确标注。若你要求这些也创新，那是另一个项目。

| 部件 | 为什么保持常规 |
|---|---|

**如果你要求这些也自研**，我建议单独立项（"自研数值栈"），
与"养育智能"并行推进，不要串行——否则第一个可运行系统要等到第五年。

## 7. "第一步完成"的可验收定义

你说"直到项目全周期全创新，才算完成第一步"。按本文标准，第一步完成 =
**下面五条全部满足**，缺一条都不算：

| # | 条件 | 检查方式 |
|---|---|---|
| 1 | 差异审计表 **100% 填满**，无空白栏 | 逐行检查，任一行 N/D/M/A 为空即不合格 |
| 2 | 每个部件的 M 栏都指向一个**已编号的实验** | 实验清单交叉核对 |
| 3 | 审计中**不存在**判定为"与已知方法无机制差别却仍留在主线"的部件 | 任何 `CONVENTIONAL` 必须移出主线或降为工具层 |
| 4 | 代码中**不存在未经审计的模块** | 扫描 `src/`，每个文件头部必须有审计编号 |
| 5 | 三个取消**在代码里可验证**：搜不到 loss/reward/action-space/policy 的痕迹 | 静态扫描 + 人工审查 |

**注意第 1 条的含义**：它不要求"每个部件都是新原理"，它要求
"每个部件都知道自己站在哪个已知方法旁边，并且说得出差别"。
这就是"没有一处是未经审计的借用"。

我认为这是"每处都创新"唯一可执行的形态。你若认为标准还不够严，
可以直接加栏（例如加"若差别 <1 个数量级则视为无差别"），我按新栏重审。
