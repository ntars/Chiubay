## 1. 为什么要复查

`docs/09 §10` 写着"配对差 95%CI 排除 0，印记比中位数 3.94×"。这是对的。
但 A3 的字面要求不是"早期效应大于晚期效应"，是：

> **晚期暴露后，结构距离变化 < 早期效应的 20%。**

前者是同一个细胞在不同时间的横断比较；后者是"晚期能不能把已有的东西改掉"。
两者不是一回事。我把代码拉出来逐项验，验出六个问题。

## 2. v1 的六个漏洞（实测，不是推测）

复查脚本只读，未修改项目。数据来自 `experiments/e3_identity_v1_retracted.py`。

| # | 文档声称 | 代码实际 | 实测证据 |
|---|---|---|---|
| 1 | 棘轮闭合，η 降到 `η0×0.1 = 0.015` | η 终值 **0.09508**，只闭合 36.7%，t=4000 后完全不动 | `eta_hist` 从 0.15 降到 0.0951 后不再变化 |
| 2 | `load` 累积到阈值 → 锁 | `load` 在 t=2000 后饱和于 **27.6**，判据是 `load > 120` | `lock_frac = 0.0`，这个判据**永远返回 0** |
| 3 | 锚点阻抗挡住晚期扰动 | 窗口内 `gate` 均值 **0.91–0.98** | 等于不挡。原因：`rho=0.005` 每步跟随，锚点永远追着权重，`dev` 恒定小 |
| 4 | 晚期进不去（剂量-反应饱和） | 晚期窗口 200→10000 步，效应 **3.3e-9 → 3.9e-7**，线性增长 | 无饱和 = 只是学得慢，不是进不去 |
| 5 | 存在关键期（某个时刻闭锁） | 扫 t0=300…11000：**非单调、无断崖，末端回升** | 300→1.06e-8，4000→−4.7e-10，11000→3.9e-9 |
| 6 | A3 成立：印记不可抹平 | 早期印记 + 长期暴露 → 残留变成"仅早期"的 **71×**（L0=60）/ **3.9×**（L0=8） | 方向反了：晚期不仅没被挡，还大幅改写了系统 |

### 2.1 根因只有一个

`文档` 说棘轮用"活动量 `|w·x|`"驱动，理由是"不随学习下降"。
**这句话是错的。** `w·x` 也是收敛量：LMS 收敛后 `w ⊥ Δx`，`|w·x|` 同步趋零。

实测载荷增量：`19.3 → 5.3 → 1.7 → 0.5 → 0.3 → 0`。

我接着测了另外三个候选，全部失败：

| 候选驱动量 | 末段速率 / 首段速率 | 结论 |
|---|---|---|
| A `Σ\|w·x\|`（活动量，v1 现用） | **0.000** | 饱和 |
| B `Σ\|Δw\|²`（塑性功） | **0.000** | 饱和 |
| C `Σ(u·x)²/\|x\|²`（感受野方向投影） | 0.305 | 仍衰减 |
| D `Σ\|err\|`（预测误差） | **0.000** | 饱和（v1 已踩过） |

**这是一条可以推广的教训**：

> 任何由"当前状态"导出的量，在系统收敛后必然趋零。用它做棘轮，
> 棘轮会在系统学会的那一刻停转——正好与敏感期相反。

唯一合格的是 **E `Σ|Δx|`（环境输入的运动量积分）**：末段/首段 = 0.958，严格单调。
它由外部驱动，与系统是否学会无关。

## 3. 修补：五个改动

### 3.1 棘轮驱动量：状态量 → 环境暴露量

```python
load += float(np.mean(np.abs(x_next - x)))    # 不是 |w·x|，不是 |err|
```

**诚实说明**：在平稳环境下，`Σ|Δx| ≈ c·t`，**数学上等价于时钟**。
它的差别只在非平稳环境（静默、节奏变化）下才显现。所以必须做可测对照：

| 场景 | dose 驱动 | clock 驱动 | 差 |
|---|---|---|---|
| 平稳 | 晚/早 = 0.0023 | 0.0017 | 无差别（符合预期，两者等价） |
| 静默 0–3000 步 | 晚/早 = **0.071** | **0.575** | **8 倍** |

静默场景下，dose 驱动的闭锁时刻从 t=431 推迟到 **t=3369**（环境贫瘠 → 棘轮慢转）。
这是"由状态驱动、不由时钟驱动"唯一的实证支持。**若去掉这一条对照，
"剂量≠时钟"就只是措辞。**

### 3.2 锚点：连续跟随 → 一次性钉住

```python
if load >= thr[i] and not frozen[i]:
    anchor[i] = w[i]          # 钉住"这就是我"
    frozen[i] = True
```

v1 用 `rho=0.005` 每步跟随，锚点永远追着权重跑，`dev` 恒小，`gate≈1`。
钉住之后 `gate` 才有实际取值（窗口内均值 0.43–0.95）。

### 3.3 指标：残留误差 → 投影量

```python
imprint = mean(|w · u|)     # u = 扰动矩阵第一左奇异向量，即"养育方向"
```

为什么必须换：v1 的残留误差跨 5 seeds 漂 **4 个数量级**（8.3e-11 … 1.6e-6），
对照组甚至可以低到 **1e-45**，比值完全失控。投影量的基线是 O(1e-2)，
同 seed 对照组的漂移在 1e-8 量级，**信噪比高 6–8 个数量级**。

### 3.4 分层可塑性（A3 与 A5 并存）

A3 要求"抹不掉"，A5 要求"还能长"，这两个在单层结构里**直接冲突**：
全部细胞同时闭锁 → 晚期任何长度的暴露都能累积出效应（实测 8000/800 = 16.8）；
全部不闭锁 → 没有不可逆。

解：按阈值高低排序，前 `identity_frac=0.67` 归**认同层**（闭锁后 η 严格为 0），
其余为**外围层**（η 保持 `eta0`，永不冻结）。

**这是设计参数，不是学出来的，标 `CONVENTIONAL`。**

### 3.5 环境稳定性（一个会导致假结论的 bug）

`make_shift(7)` 把谱半径从 0.850 推到 **1.009**，60000 步后权重发散，报告出 `nan`。
若没发现，会被读成"印记丢失"。现在 `make_shift` 带 `a_mat` 参数，
用二分搜索收缩幅度，保证 `A+shift` 谱半径 ≤ 0.88。

## 4. v2 结果 —— **整节作废**

> **本节全部结论已于 2026-11-27 撤回。** 原因见 §9：学习规则不动点是 `w=0`，
> v2 测到的是权重崩塌残余，不是学习的结果。原文保留如下，作为"错在哪"的记录，
> **不得作为证据引用**。

`experiments/e3_identity.py` → `runs/e3_identity/report_v2.json`。

### 4.1 当时认为成立的三条（已撤回）

| # | 当时的结论 | 数据 | 撤回原因 |
|---|---|---|---|
| 1 | 等剂量下，晚期学不进去 | 5 seeds 晚/早 = 0.00001–0.0033 | 权重在塌向零，两次都"没学到"，比值由噪声决定 |
| 2 | 换了养育方式，原印记还在 | 保留 1.013，95%CI [1.000, 1.032] | 实测 `(A→无)/A = 1.000`（5/5 seeds）：换 B 与什么都不做等效，keep≈1 是平凡的 |
| 3 | 认同层锁死后，外围层仍能学 | 认同层投影不变；外围层投影动了 | `load` 是全局标量，外围层 η 实测也是 1.01e-4（保留 0.034%）；判据阈值 1e-6 属伪阳性。**分层从未实现** |

### 4.2 被"推翻"的两条假设 —— **推翻本身是 bug 导致的**

| 当时的判断 | 当时的实测 | 现在的判定 |
|---|---|---|
| "必须硬冻结才能不可逆，软阻抗只能减慢" | `frozen_eta` 晚/早 = 0.0000，故"gate 单独就够" | **该实测无效**。`use_layer = mode in ("full","no_gate","frozen_eta")` 把 `frozen_eta` 也放进了分层分支，所以"η 恒定 + gate"实际上**仍在硬冻结**。修正后 E3c 六类环境五类分离 |
| "软约束 60k 后会被抹平" | 软阻抗 60k 保留 1.000 | 同上，受 bug 污染，且 `w→0` 使该结论无意义 |

**教训**：一个消融实验如果"证明"了某个组件冗余，先检查那个组件是否
真的被关掉了。`gate_in_window` 实测恒为 1.0000、`full` 与 `no_gate` 逐位相同，
这两个信号当时就在输出里，我没有看。

## 6. 方案仍缺的东西（按是否阻塞排序）

这是回答用户原问题的主体。以下按"不做会卡住什么"排。

| # | 缺口 | 为什么阻塞 | 建议 |
|---|---|---|---|
| **1** | **没有死亡判据** | ⑥ 代谢的牙齿是"维持不住就退化"，但全文没有阈值、没有观测协议。A1 只要求"不发散"。**没有死，就没有活**——永不死的东西，"存续"是默认值不是成就，E6 无法判定"目标从内部产生" | 先写一个粗糙的：活动量低于阈值持续 N 步 → 判定退化。有比没有强 |

  方案里没有给出任何"为什么参数会自己变得不可写"的机制。
- 局部学习规则仍是 LMS（1960）的预测形式，`CONVENTIONAL`。
- 关键期没有断崖这一点，在两代装置上都成立。

## 9. 第二轮复查：装置是坏的（2026-11-27）

### 9.1 问题的发现路径

我先在修 `C3_slow_env` 的 `nan`。修的过程中发现 `make_shift` 在不可行时
静默返回零矩阵——这是本轮的**第一个**静默失效。

最后为了构造一个"局部误差驱动 η"的替代方案，需要"误差"这个量，
才发现 `err = w·dx` 会随 `w` 一起归零——**这时才去测 `‖w‖`，

**五次连续的"顺手查一下"，每一次都指向更深的地方。**
如果我在任何一步停下来（比如把 C3 的 `nan` 改成 `np.nanmean` 就交付），
这一轮什么都不会发现。

### 9.4 下一步的唯一悬念

### 9.5 第三轮：指标没有信噪比，实验无法测出养育

修完装置、修完分层之后，结果仍然全是否定的，而且这次否定的对象是实验设计本身。

用完美值校准指标，它是好的：

```
完美收敛 w = A      -> imprint = -1.0（全部 -1）
完美收敛 w = A + S  -> imprint = +1.0（全部 +1）
```

用实际学到的权重，它失效：

```
w 与 A 的距离:   [0.243 0.352 0.255 0.301 0.326 0.106]
||S_i||（信号）: [0.073 0.028 0.194 0.245 0.045 0.203]
```

**噪声底（LMS 稳态误调 0.24–0.35）大于要测的信号（0.03–0.25）。**
后果是两个方向都被压成负值：

```
只学 A -> 对 A 的印记 = -0.0845    对 B 的印记 = -0.0968
只学 B -> 对 A 的印记 = -0.1100    对 B 的印记 = -0.0685
```

**"只学 A"对 A 的印记是负的。** 这意味着即使给系统完美单一的养育，
指标也测不出来 —— 不是因为机制不对，是因为实验从未有过足够的信噪比。

这条已写成测试 `test_signal_exceeds_noise_floor`，把"当前信号被淹没"
钉死在测试里。将来若参数改进使 signal > noise，该测试会失败并提醒重跑。

### 9.6 这一轮的净结果

**没有任何一条正面结论。** 逐条列清楚：

| 项 | 状态 |
|---|---|
| 学习规则 | ❌ v1–v3 全用错（不动点 `w=0`）。v4 的预测式 LMS 有效，但是 1960 年的已知方法 |
| 不可逆（A3） | ❌ 只在硬锁下成立，硬锁是 `if frozen: η=0`，不是机制 |
| 可生长（A5） | ❌ 全部机制下印记为负。且参照组"只学 B"本身即为负 |
| 指标 | ❌ 信噪比不足，噪声底是信号的 1–10 倍 |
| 分层 | ⚠️ 修好了因果（认同层=先闭锁的那批，在线确定），但 A5 仍不成立 |
| 关键期 | ❌ 两代装置上都没有断崖 |
| gate | ❌ 在 v2 设计里是空操作（`gate_in_window` 恒 1.0000） |
| 多份实现不同步 | ❌ 本轮第 5 次遇到（`e3d` 自带一份 `develop`，与 core 分叉后得出两套数字） |

**能留下的，全是方法：**

1. 任何 `f(当前状态)` 不能做棘轮驱动量（`w·x` 饱和、`|err|` 饱和、`|Δw|²` 饱和）。
2. 全局标量驱动逐细胞参数 = 没有分层。
3. 判据阈值必须用效应量，"变化 > 1e-6" 会让抖动通过。
4. 比值 ≈1 必须排除"两边都没动"。
5. 不可行条件必须抛异常，不得静默退化（`make_shift` 返回零矩阵）。
6. 跨机制比 `late/early` 不公平（分母由条件自定）。
7. **实验开跑前必须先测信噪比**，否则测的是稳态误调。
8. 同一逻辑只写一份实现，副本必然分叉。

**第 7 条是这一轮最贵的教训。** 我在前三轮里一直在调指标、调判据、调参数，
却没有先问一句"要测的效应比噪声大吗"。这一个问题的答案是"不"，前面全部作废。

### 9.7 信噪比的三个可能出路，已试掉一个

| 方向 | 做法 | 结果 |
|---|---|---|
| (a) 加大扰动 | 提高 `amp` | ❌ 受限：`spec(A+S) ≤ 0.88`，`amp` 提高会被 `make_shift` 收缩回去 |
| (b) 降低稳态误调 | 更长 η 衰减 / RLS | 未试。LMS 误调 ∝ `η·tr(R)`，理论可降，但会同时减慢学习 |
| (c) 换指标 | `score = MSE(A环境) − MSE(B环境)` | ❌ **已试，失败** |

方向 (c) 的实测（3 seeds，`score > 0` 表示更像 A）：

```
seed0  学A: score = -0.000213     学B: score = +0.000196
seed1  学A: score = -0.000304     学B: score = -0.000230
seed2  学A: score = -0.000753     学B: score = -0.000092
```

seed0 方向正确（互反），但 seed1/seed2 里"学 A"与"学 B"的 score
几乎同号同量级，**系统无法区分两个环境**。这从另一个角度印证同一结论：

> 在当前扰动幅度下，6 个细胞无法把养育方式写进权重。
> 秩 1 扰动只给 24 维系统一个方向的信息，而噪声在每个维度上都在作用。

**所以"③ 不成立"目前只能写作"在本实验的信噪比下测不出"，
不能写作"机制不成立"。** 这个区分很重要：前者是实验问题，后者是方案问题。

下一步只能是方向 (b)：降低稳态误调。在此之前 ③ 的所有机制结论都悬置。

### 9.8 第四轮：信噪比修好了，但闭锁机制与"学会"直接冲突

> **⚠️ 本节的三个数字已撤回（v2.1）。** 保留原文作为"误读的标本"。
> 撤回理由见 §10.1：`30k–100k 步`是把 LMS 的**稳态误调地板**当成收敛时间；
> `20–100 倍时间尺度冲突`随之作废；`30k 步 0.056`不可复现（实测 0.2224）。
> 本节结论中仍然成立的部分：信噪比确实修好了（S/N 1.70）、理想 MLE 确实
> 达到 +0.78~+0.85、`D_lock` 全区间内印记确实随闭锁数单调下降。

先修了信噪比（`d=12`、`amp=2.5`、`gamma=2.0`），S/N 从 0.50 提到 **1.70**。
指标首次能分辨信号。用这个装置算理想上界：

**理想 MLE（对养育环境做批量最小二乘）的印记 = +0.827 / +0.784 / +0.846**
（3 seeds，残差 0.013–0.025）

所以**实验设计本身没问题**，理想解远高于 A5 门槛 0.15。问题在别处：

| 配置 | 锁定中位 | `‖w−(A+B)‖` | 印记 B |
|---|---|---|---|
| D_lock=0.05 | 1943 | 0.4236 | −0.5653 |
| D_lock=0.10 | 1283 | 0.3556 | −0.3145 |
| D_lock=0.15 | 1092 | 0.2799 | −0.0310 |
| D_lock=0.25 | 792 | 0.2885 | +0.0260 |
| D_lock=0.40 | 529 | 0.3735 | −0.1263 |
| **理想 MLE** | — | **0.013–0.025** | **+0.78 ~ +0.85** |

**在线 LMS + 闭锁，最好也只到 +0.026，比理想解差 30 倍。**

而同一套在线 LMS **去掉闭锁**，30k 步可达 `‖w−(A+B)‖=0.056`，
100k 步达 0.040 —— 比带闭锁的任何配置都好。

结论：

> **闭锁（③ 的核心机制）与"学会世界"直接冲突。**
> 闭锁让细胞在 529–1943 步就停止学习，而 LMS 需要 30k–100k 步
> 才能把权重压到信号水平。两者差 20–100 倍时间尺度。

这不是参数问题。任何"早期停止学习"的机制，在一个需要长时学习的
局部规则上，都必然导致"没学会就被冻住"。而要"学过之后再冻"，
就必须先让 LMS 跑够 30k+ 步 —— 那时"早期"已经占整个发育期的 2/3，
"关键期"就不存在了。

### 9.9 于是 ③ 的问题被重新表述

> **⚠️ 本节的"问题表述"基于 §9.8 的错误前提（LMS 学得慢），已作废。**
> 真实问题不是"在一个学习很慢的规则上早期闭锁是否可行"——规则并不慢
> （η 衰减 2000 步即到 0.111）。真实问题是 §10.4：
> **A3 与 A5 要在同一 seed 上同时成立，就必须让"闭锁"与"可学习"
> 作用在不同的物理量上。** 下面三条出路只有第 2、3 条仍然有效。

原表述："不可逆与可生长能否并存？"
真正的问题在更前面：

> ~~**在一个学习很慢的局部规则上，"早期闭锁"这个机制本身是否可行？**~~

三条路，都不在现有方案里：

1. ~~**换更快的学习规则**（RLS / 递归最小二乘）。~~
   **作废**：前提是"规则太慢"。实测 η 衰减 2000 步就到 0.111，
   瓶颈不是收敛速度，而是 η 一旦降下来就再也上不去（A5 需要后期还能学）。
   RLS 同样会让后期 η 变小，不解决问题。
2. **闭锁的对象不是参数，是"哪条通路存在"**（结构）。这样"冻结"不阻止
   剩余通路继续学习，A3 与 A5 不再争夺同一批参数。这要求 ④ 先有代码。
3. **承认 ③ 不成立**，把"不可逆"从第一版方案里去掉，只保留
   "早期经历影响后期"（弱主张），并如实写在 `docs/09` 的验收表里。

我倾向第 2 条，但它是 ④ 的工作，而 ④ 目前只有纸面。
**在第 2 条有代码之前，③ 处于"设计失败、待重设计"状态，不是"待验证"。**

## 10. 第五轮：§9.8 的三个数字全是错的（v2.1）

上一节写完"我不再跑 ③ 的任何实验"，我违背了它——因为复查一个测试时发现
`‖W−A‖/‖A‖` 在 4000 步已是 0.39，而 §9.8 说"需要 30k–100k 步"。
两者必有一错。本轮把这条追到底，结果是**文档错了**。

### 10.1 三个被推翻的数字

**（1）"在线 LMS 需要 30k–100k 步收敛" —— 错，是误调地板**

实测 `mode=none`（η 恒定 0.30）、无养育、目标 A：

| 步数 | 500 | 1000 | 2000 | 4000 | 8000 | 14000 | 30000 |
|---|---|---|---|---|---|---|---|
| `‖W−A‖/‖A‖` | 0.416 | 0.403 | 0.434 | 0.390 | 0.401 | 0.386 | 0.420 |

**加 60 倍步数，误差不下降。** 这不是"收敛慢"，是 LMS 的稳态误调
`≈ η·tr(R)/2`，**与步数无关**。我把它读成了"需要更多步"。

改 η 衰减（`mode=eta_only`）后：

| 步数 | 500 | 1000 | 2000 | 4000 | 8000 | 30000 |
|---|---|---|---|---|---|---|
| `‖W−A‖/‖A‖` | 0.205 | 0.141 | **0.111** | 0.099 | 0.117 | 0.077 |

**2000 步就到 0.111。** 不存在 30k 步才能收敛这回事。

**（2）"闭锁与学习差 20–100 倍时间尺度" —— 基于（1），作废**

两条已写成测试：`test_constant_eta_never_converges`、
`test_eta_decay_converges_fast`。

**（3）"去掉闭锁 30k 步可达 `‖w−(A+B)‖=0.056`" —— 不可复现**

同条件实测：4000/8000/14000/20000/30000 步分别为
0.2248 / 0.2674 / 0.2179 / 0.2299 / **0.2224**。基本不随步数变化。
原始 0.056 来源不明，撤回。

### 10.2 A3 的旧测量设计混淆了剂量与巩固时间

比上面三个数字更严重。`e3d_emergence.py` 与 §9.8 用：

```
早期窗口 (300, 4300)       → 窗口关闭后还有 25,700 步继续学习
晚期窗口 (TT-4800, TT-800) → 窗口关闭后只剩      800 步
```

**剂量相同（4000 步），但窗口关闭到测量的"巩固时间"差 24,900 步。**
所以"晚/早"比值测的是**恢复速度**，不是不可逆性：早期条件有大把时间恢复，
晚期没有。那个 `0.0057` 因此毫无意义——它不证明任何事。

修正（`experiments/e3e_redesign.py`）：等剂量 4000 + 等巩固 6000，
**只改窗口年龄**（早期起点 300，晚期起点 20000），效应定义为
`‖w(有养育) − w(无养育对照)‖`，两条件测量时刻相同。

| mode | D_lock | 效应早 | 效应晚 | 晚/早 | A3 |
|---|---|---|---|---|---|
| full | 0.25 | 0.482 | 0.0089 | **+0.022** | ✅ |
| full | 0.40 | 0.398 | 0.0149 | **+0.034** | ✅ |
| eta_only | 0.25 | 0.072 | 0.0509 | +0.644 | ❌ |
| soft | 0.25 | 0.483 | 0.0748 | +0.149 | ✅ |

两条新事实：

1. **A3 可以成立**，且比值与判据门槛（0.20）差一个量级，不是勉强通过。
2. **`eta_only`（只有 η 衰减、不闭锁）给不出 A3**（0.644）。所以 A3 确实
   需要某种"窗口关闭"。这比 §9.8 的"硬锁是构造所以不算"更精确：
   需要的不是 `if frozen: eta=0` 那一行，而是**一定数量的细胞在窗口关闭前
   停止更新**。

### 10.3 闭锁对 A5 的隔离：是我上一轮唯一搞对的方向

`D_lock=0` 时**没有任何细胞闭锁**，此时：

| D_lock | 闭锁数 | A5 印记 | 更接近 A+S 的细胞比例 |
|---|---|---|---|
| 0.00 | 0/12 | **+0.278** | 67% |
| 0.10 | 5/12 | +0.093 | 25% |
| 0.15 | 7/12 | −0.019 | 17% |

闭锁数单调增加，A5 单调塌陷。**A5 的失败由闭锁直接造成，与 η 衰减无关**
（这条隔离做干净了：`D_lock=0` 保留全部 η 衰减，A5 仍达 +0.278）。

### 10.4 "并存"是边界抖动伪造的

细扫 `D_lock` 时在 0.075 处出现：

```

A5 = 0.1550（判据 0.15，刚好过）
```

| seed | A3 | A5 | 同时 |
|---|---|---|---|
| 0 | +0.055 | +0.155 | ✅ |
| 1 | +0.481 | +0.350 | ❌ |
| 2 | +0.052 | +0.042 | ❌ |
| 3 | +0.248 | +0.155 | ❌ |
| 4 | +0.030 | +0.012 | ❌ |
| 5 | +0.208 | +0.164 | ❌ |
| 6 | +0.195 | +0.218 | ✅ |
| 7 | +0.202 | +0.517 | ❌ |
| 8 | +0.086 | +0.146 | ❌ |
| 9 | +0.043 | +0.328 | ✅ |


> **新的判据（写死）：A3 与 A5 必须在同一 seed 上同时成立，且跨 seed 稳定。

这一条是本轮唯一的方法论收获：**"每个判据都能在某个参数下通过"不等于
"两个判据能同时通过"。** 上一轮我拿不同参数下的两个最好值拼出一张表，
看上去像"并存",实际没有一次运行同时满足。

### 10.5 imprint 的零点在"无偏好"，不在 `w=A`

一个反复误导我的误解。实测三点（`d=12`，无养育的 A 与养育后的 A+S）：

| 状态 | imprint 均值 | 含义 |
|---|---|---|
| `w=0` | −0.0245 | 无偏好（值域 −0.17~+0.07） |
| `w=A` | **−1.000** | 完全记住旧环境 |
| `w=A+S` | **+1.000** | 完全吸收养育 |

**`w=A` 时印记是 −1，不是 0。** 后果：闭锁细胞的印记必然为负，而那是
**A3 成立**（"没被养育改动"）的证据。我上一轮把闭锁细胞和外围细胞放进
同一个平均值，负号吃掉正号，得到"A3 与 A5 都不成立"的假象。

正确做法：**A3 只在闭锁细胞上测（期望负），A5 只在未闭锁细胞上测（期望正）。**
已写成测试 `test_a3_and_a5_measured_on_disjoint_cells`。

| **v4.2 五轮** | **"A3 可成立；A5 被同一机制削弱；二者不可靠并存"** | ← 当前 |

不是"设计失败"，也不是"待验证"：

> **A3 有可复现的实现路径（0.022–0.055，判据 0.20）；
> A5 在该实现下必然被削弱（闭锁数越多越差，隔离干净）；
> 两者的联合成立率 3/10，属边界抖动而非机制。**

要让两者并存，必须让"闭锁"与"可学习"作用在**不同的物理量**上
（结构 vs 参数），而不是在同一批参数上争夺 η。这仍然指向 ④。

**所以 §11 把 E4 放在 ③ 之前，不是"下一步之一"，而是前置条件。**
