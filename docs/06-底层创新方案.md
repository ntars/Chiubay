## 2. 底层创新的核心命题

### 2.1 一句话

**生物脑不是函数逼近器，是一个"维持自身存续"的系统：
它预测自己的输入，用预测失败来重组自己，并且全程可被外部读取和改写。**

这句话里每个分句都对应一个机制，且都跟当前 AI 的做法相反：

| 分句 | 当前 AI 的做法 | 本项目 |
|---|---|---|
| 预测自己的输入 | 预测标签/下一 token | 预测**输入本身**（自监督，无标签） |
| 用预测失败重组自己 | 用损失调权重 | 用失败**改结构**（增删单元） |
| 维持自身存续 | 无此概念 | **稳态约束**是唯一的目标 |
| 可被外部读取改写 | 事后做可解释性 | **可读性是一等公民** |

### 2.2 根本差异：没有全局损失函数

这是全部创新的支点。当前所有深度学习系统都是：

```
loss = f(全体参数)  →  ∂loss/∂θ  →  更新
```

本项目：

```
每个单元有自己的局部误差  →  只更新自己  →  单元之间靠信号耦合
```

**没有哪个标量代表"整体好不好"。** 系统不知道自己在做任务，
它只知道"我预测错了"和"我的活动量偏离了正常范围"。

这个差异不是哲学表态，它有一个直接可测的后果：
**你无法通过最小化某个损失来训练它**，因此也无法用常规训练流程复现它。

## 3. 四个创新点

每个创新点给：机制 / 与已知方法的**精确**差别 / 可证伪判据。

### 3.1 创新点 A：树突分室（Dendritic Compartment）

**机制。** 一个单元不是一个点，是若干「分室」的集合：

```
第 b 个分室：  z_b = φ( Σ_i w_bi · x_i )        φ = 分室非线性（阈值+饱和）
单元输出：      y   = Σ_b  a_b · z_b              a_b = 分室增益（可塑）
```

关键不在公式，在**学习信号**：每个分室有自己的局部预测目标——
「预测自己这一支收到的输入」。误差是：

```
e_b = x_i − ŵ_bi            （分室对输入的局部重建误差）
Δw_bi ∝ e_b · z_b           （局部规则，无梯度回传）
```

**与已知方法的精确差别：**

- 跟 MLP 比：MLP 只有一个全局损失，梯度从输出层回传；这里每个分室
  独立自监督，**不需要知道下游要什么**。
- 跟稀疏编码/字典学习比：那些是单层、无层级误差；这里是分层、每层
  都在预测下一层的输入。
- 跟预测编码（Rao & Ballard 1999）比：预测编码的分室是**同一层内**
  做误差单元；这里的分室**各自有不同的感受野和时间常数**，
  且增益 `a_b` 受调制信号控制（见创新点 B）。

**可证伪判据：** 把分室数设为 1（退化成点神经元），同等参数量下：
- 若性能不变 → 分室是装饰，删掉；
- 若性能下降 >20% → 分室承载了真实计算。

**这是本文最容易被质疑为"已知技术"的一条，必须靠消融数据站住。**

### 3.2 创新点 B：调制向量（Modulatory Vector），不是奖励标量

**机制。** 系统里没有 `reward: float`。有的是一个四维调制向量：

```
m = [新奇度, 预测误差, 活动量偏离, 社会信号]
```

它**不进入任何梯度**，也不参与损失计算。它的作用是**重配可塑性规则**：

```
Δw = Σ_k  m_k · R_k(w, x, z)      R_k 是第 k 种可塑性规则
```

- `m_新奇` 高 → 加大结构可塑性（长新分室/新单元）
- `m_误差` 高 → 加大权重可塑性（改连接）
- `m_活动偏离` 高 → 触发稳态（缩放权重，见创新点 D）
- `m_社会` 高 → 进入模仿模式（但只用于建模，见 §4）

**与已知方法的精确差别：**

- 跟 RL 比：RL 的 reward 是**标量**，含义是"好/坏"，进入梯度。
  这里的调制是**向量**，含义是"现在该用哪种学习方式"，不进梯度。
- 跟神经调制（多巴胺/乙酰胆碱）比：这是**功能类比**，不是模拟。
  没有膜电位、没有脉冲、没有神经递质动力学。
- 跟元学习（MAML）比：MAML 学的是"好的初始化参数"；这里改的是
  **哪条规则生效**，参数本身不在元层面被优化。

**可证伪判据：** 把 `m` 固定为常数（等价于固定学习率）：
- 若性能不变 → 调制无用，退化为单规则；
- 若性能下降 → 调制承载了"在不同处境切换学习方式"的功能。

### 3.3 创新点 C：父母脚手架——示范只用于建模，不用于克隆

**机制。** 父母提供一个动作 `a_parent`，但**孩子不复制它**。
`a_parent` 的唯一用途是给世界模型打标签：

```
世界模型学：  (s, a_parent) → s′        "这个动作导致了什么"
孩子自己决策： a_child = argmax_a  D( f(s,a) )   （D = 先天驱力）
```

**与已知方法的精确差别：**

- 跟行为克隆比：克隆是 `π ← argmin ‖π(s) − a_parent‖`，会复制父母的错误；
  这里**没有任何策略参数**，父母的动作只进入因果模型。
- 跟逆强化学习比：IRL 从示范里**推断奖励函数**；这里不推断奖励，
  只学转移。奖励从头到尾不存在。
- 跟 DAgger 比：DAgger 是交互式纠正策略；这里父母不纠正策略，
  只提供"这个动作会发生什么"的数据。

**可证伪判据（这条实验最干净）：**

给一个**次优父母**——故意让 30% 的示范动作是错的（随机动作）。
- 行为克隆：性能应该被拖累到接近 70% 正确率；
- 本项目：若世界模型能识别"这个动作没达到它通常的效果"，
  性能应该**不受影响**，甚至更好（错误示范提供了反例信息）。

若两者性能一样 → 说明本项目实际上还是在克隆，只是包装不同。

### 3.4 创新点 D：自读头 + 结构可塑性（BCI 的功能对应）

**机制。** 系统有一个读出头，解码自己的隐藏状态：

```
自读：  h_t  →  预测 (h_{t+1}, a_{t+1})
```

这是"读自己"。读出准确 = 有自我模型。然后：

**当自读发现"我在某类处境下总是预测错自己"** → 触发**结构分裂**：

```
若 局部预测误差 > 阈值 且 持续 N 步：
    复制该处单元 → 新单元继承权重 + 小扰动 → 两者分工（互相抑制）
若 某单元长期不被激活：
    修剪
```

**与已知方法的精确差别：**

- 跟 MoE 比：MoE 的专家数**固定**，路由是学出来的；这里专家数**会变**，
  分裂由自读误差触发，不是由任务损失触发。
- 跟神经进化（NEAT）比：NEAT 靠**适应度**（全局标量）选择结构；
  这里没有适应度，只有局部预测误差。
- 跟元学习比：元学习改参数，这里改**拓扑**。
- 跟 BCI 比：这是功能对应——BCI 读神经活动控制外部设备；
  这里读自身活动决定是否改造自己。**闭环在系统内部。**

**可证伪判据：** 关掉自读头（不触发分裂）：
- 若性能不变 → 自读是装饰；
- 若性能停滞在某水平 → 自读承载了"知道自己不会"的能力。

### 3.5 四条创新的关系

它们不是并列的模块，是**三个耦合环**：

```
        ┌──────────── 环1 预测环 ────────────┐
        │  分室做局部预测，最小化局部误差      │
        └──────────────┬─────────────────────┘
                       │ 误差信号
        ┌──────────────▼─────────────────────┐
        │  环3 调制环：误差/新奇/活动 → 切换规则 │
        └──────────────┬─────────────────────┘
                       │ 规则选择
        ┌──────────────▼─────────────────────┐
        │  环2 发育环：自读 → 分裂/修剪/稳态   │
        └────────────────────────────────────┘
```

**没有全局损失。** 三个环各自局部收敛，整体行为是涌现的。
这是全文唯一真正的创新主张，也是唯一值得写进结论的东西。

## 4. LSE 的去留

**结论：LSE 降级为"分室银行的实现载体"，不再是架构中心。**

| LSE 组件 | 处置 | 理由 |
|---|---|---|
| ExpertBank | 改造成 CompartmentBank | 一次 GEMM 算全部分室，这个实现技巧保留 |
| Top-K Gate | **删除** | 它是 MoE 的路由，属已知架构 |
| LinkageBridge | **删除** | 已实测无增益（M1：0.096 vs 0.042，更差） |
| Decoder | 保留为读出层 | 普通线性层，无争议 |

**新的门控不是 Top-K，是分室增益 `a_b`**，由调制向量控制，
不是由输入学出来的路由。这是关键区别：Top-K 是"选谁工作"，
分室增益是"谁现在更敏感"——后者是连续调制，不是离散选择。

## 5. 学习机制总览

### 5.1 三种可塑性，各自独立

| 类型 | 时间尺度 | 触发 | 更新对象 | 是否用梯度 |
|---|---|---|---|---|
| 权重可塑性 | 快（每步） | 局部预测误差 | `w_bi` | 否，局部规则 |
| 增益可塑性 | 中（每 episode） | 调制向量 | `a_b` | 否，稳态调节 |
| 结构可塑性 | 慢（每 N 步） | 自读持续失败 | 分室增删 | 否，阈值规则 |

**三者都不经过反向传播。** 自研张量引擎仅用于**前向计算**与
**世界模型的可选对照**（ADR-002 §3.6）。

### 5.2 局部规则的形式

分室 `b` 对输入维 `i` 的权重更新：

```
e_bi   = x_i − ŵ_bi                   局部重建误差
h_bi   = z_b · (1 − z_b)              分室活动的导数（饱和区不学）
Δw_bi  = η · m_误差 · e_bi · h_bi     η 由 m_活动偏离 调节
```

这不是反向传播：`e_bi` 是**该分室自己的**误差，不来自下游。
`h_bi` 是分室局部的饱和项，防止权重爆炸——这是生物神经元的
固有性质（放电率有上界），不是梯度裁剪。

**必须诚实标注**：这个形式与**赫布学习 + Oja 规则**高度相似。
差别在于误差项 `e_bi` 是**预测误差**而非"输出×输入"，
且被调制向量门控。**不声称是全新规则。**

### 5.3 稳态约束（唯一的"目标"）

系统没有损失，但有**约束**：

```
‖y‖² ≈ 目标活动量          （突触缩放）
Σ_b a_b ≈ 常数              （增益归一）
参数量 ≤ 预算               （结构上限）
```

约束被违反时，触发调节，不产生梯度。这是"维持存续"的具体含义：
系统不追求"更好"，只追求"不偏离可工作区间"。

## 6. 发育阶段（父母角色重定义）

| 阶段 | 父母做什么 | 孩子学什么 | 退场条件 |
|---|---|---|---|
| **S0** | 无 | 纯自监督：预测自己的输入 | 预测误差进入平台期 |
| **S1** | 示范（次优，含 30% 错误） | 从示范学因果，不学动作 | 见 §3.3 判据 |
| **S2** | 结构化环境（摆出课程） | 在新奇度驱动下自主探索 | 覆盖率达到阈值 |
| **S3** | 提供"社会信号"调制 | 学会"看眼色"调整学习模式 | 社会信号预测准确率 |
| **S4** | 撤退 | 自我修改（§3.4） | 修改成功率 + 可回滚 |
| **S5** | 无 | 开放式发育，无终点 | 无（持续） |

**关键设计**：父母**从不给奖励**。给的是示范、环境结构、社会信号。
这三样都不进入参数更新的梯度——因为它们不产生梯度。

## 7. 评估

### 7.1 四层指标

| 层 | 指标 | 说明 |
|---|---|---|
| **局部** | 分室重建误差 | 每个分室自己的误差，不是全局损失 |
| **自读** | 自读准确率（预测自己的下一状态/动作） | 元认知 |
| **行为** | 任务成功率（**仅作参照，不作主指标**） | 系统不知道任务 |
| **结构** | 分室增删历史、稳态偏离度 | 发育轨迹 |

**主指标不是任务成功率。** 这是与常规 AI 最根本的评估差异：
一个只会做任务但不会发育的系统，在本项目里是失败的。

### 7.2 必须做的对照（按重要性排序）

| 实验 | 对照 | 检验 |
|---|---|---|
| **E1 次优父母** | 克隆 vs 建模 | 创新点 C（最干净） |
| **E2 去分室** | 分室数 1 vs N | 创新点 A |
| **E3 常数调制** | `m` 固定 vs 变化 | 创新点 B |
| **E4 关自读** | 有/无分裂 | 创新点 D |
| **E5 全局损失上界** | 用反向传播训练同样结构 | 局部规则差多少（诚实基线） |

E5 必须有：如果局部规则比反向传播差 10 倍，报告必须写"差 10 倍"，
不能只写"局部规则可行"。

### 7.3 停止条件

1. E1 显示建模与克隆无差别 → 创新点 C 不成立，整个"父母"叙事作废。
2. E2 显示分室无贡献 → 退回点神经元，创新点 A 作废。
3. E5 显示局部规则差 100 倍以上，且无改进趋势 → 项目定位改为
   "局部规则的可行性边界研究"，不再声称能支撑复杂行为。

## 8. 与已知方法的边界（诚实标注，不得删减）

| 本项目 | 最近邻 | 差别 | 是否声称创新 |
|---|---|---|---|
| 树突分室 | 预测编码、稀疏编码 | 分室感受野不同 + 增益受调制 | **弱**，组合层面 |
| 局部规则 | 赫布/Oja、三因子规则 | 误差是预测误差，被调制门控 | **弱**，形式层面 |
| 调制向量 | 神经调制、元学习 | 切换规则而非优化参数 | **中** |
| 示范用于建模 | 逆模型学习、世界模型 | 明确禁止克隆，有对照实验 | **中** |
| 自读触发分裂 | NEAT、MoE、元学习 | 触发信号是自读一致性而非适应度 | **中** |
| 三环无全局损失 | 无 | — | **这是唯一强主张** |

**"三环无全局损失"是本文唯一值得辩护的创新。** 其余都是已有思想的
重新组合，必须如实标注。任何一处写成"首次提出"都是学术不诚实。

## 9. 实现顺序

| 步骤 | 内容 | 依赖 | 产出 |
|---|---|---|---|
| **A0** | 分室单元 + 局部规则（单层，XOR 级任务） | 无 | 验证局部规则能学 |
| **A1** | 多层分室 + 稳态 | A0 | 验证深层不崩 |
| **A2** | 自读头 | A1 | 自读准确率 |
| **A3** | 结构分裂/修剪 | A2 | 发育轨迹 |
| **A4** | 调制向量 | A3 | E3 消融 |
| **A5** | 父母示范（次优） | A4 | E1 关键实验 |
| **A6** | 沙盒接入（改造 GridWorld） | A5 | 端到端 |

**A0 是生死关。** 如果单层局部规则连 XOR 都学不会，后面全部无意义。
A0 通过标准：XOR 100%，且与反向传播版本的差距 <5 倍。
