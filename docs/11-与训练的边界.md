# 12. 与"训练"的边界：一份自我判决（v4.3）

> **这一节回答一个问题："你这套东西和训练 AI 大模型有什么不同？"**
>
> 答案是：**当前 ③ 没有本质不同。** 本节给出数学证明，然后给出
> "要不同必须做到什么"的判据，以及四次失败的尝试记录。
>
> 这一节的作用不是辩护，是**把不合格的方案判死**，免得继续在
> 换个名字的训练循环上花时间。

---

## 12.1 判据：什么算"训练"

不用口号，用可判定的数学条件。

设可塑性规则在参数空间上定义了一个更新场 `F(W) = E[ΔW | W]`。
**若存在标量函数 `L(W)` 使得 `F = −∂L/∂W`，则这个系统在做"训练"。**

理由：优化一个 `L` 就是沿某个方向下山。任何下山过程都被同一个 `L`
度量，行为完全由 `L` 的形状决定。换名字、换分层、换冻结时机，
都只是换步长或换停步位置，**不改变"在训练"这个性质**。

可操作的检验（Helmholtz 分解）：梯度场的雅可比必然对称，因为
`∂²L/∂w_a∂w_b` 可交换。

```
J[a,b] = ∂F_a/∂W_b（W 展平成向量）
J 对称   ⟺  存在 L  ⟺  这是训练
J 非对称 ⟹  curl F ≠ 0 ⟹ 不存在任何 L ⟹ 这不是训练
```

---

## 12.2 实测：③ 的更新场是非对称度 1e-10 的梯度场

`experiments/e4a_is_this_training.py`，参数空间 6×12 = 72 维，
中心差分雅可比：

| 规则 | 非对称度 | 判定 |
|---|---|---|
| LMS（η=0.30 全场统一） | **1.1e-10** | 训练（存在势函数） |
| LMS（η=0.05） | **1.1e-10** | 训练 |
| 逐细胞 η 分层（0.3 / 0.003 混合） | **1.2e-10** | 训练 |
| 逐细胞 η 全零（=冻结） | **0.0** | 训练（退化） |
| LMS + 反对称旋转（人造反例） | 2.0 | 非训练 |

**"可塑性分层"没有改变场的性质。** 原因是：逐坐标不同的 η 是
**逐坐标的正缩放**，`Δw_i = −η_i·∂L/∂w_i`，`η_i > 0`。
正缩放后的场仍是梯度场（雅可比只是被对角相似变换了一下，对称性不变）。

**"闭锁"同理。** `η_i = 0` 只是把该坐标的更新置零，仍是退化的梯度场。

### 解析验证

`L = (1/(S·n))·Σ err²` 的梯度是 `−(2/(S·n))·E[err xᵀ]`。
逐细胞规则 `Δw_i = η·err_i·x` 与它的相对差：

```
rel diff = 5.5e-10
```

**即机器精度。** 所以：

> **"无全局损失、纯局部"在数学上不成立。**
> 这套规则满足"局部计算"（每个细胞只用 `err_i` 和 `x`），
> 但不满足"无全局目标"（它精确地最小化一个全局 MSE）。

这是 `docs/09` §5 ② 栏"无 obs/action/reward"的真正漏洞：
**没有 reward 不等于没有目标函数。** MSE 就是一个目标函数。

## 12.3 所以当前 ③ 是什么

诚实的描述：

> **一层线性回归 + SGD + 学习率退火 + 冻结表。**
> 预测式 LMS 是 Widrow–Hoff 1960，规则本身属 `CONVENTIONAL`。
> 分层与闭锁是调度策略，不是新规则。

这不是创新。我在 `docs/09` §5 ③ 栏把它标成 `PENDING` 是对的，
但理由一直没说透：**它不只是"没验证通过"，而是"验证通过了也不是创新"。**

---

## 12.4 要"不是训练"，必须做到什么

判据：`F` 必须含**不可积分量**（curl ≠ 0），使系统不可能收敛到任何
单一 `L` 的极小点。

最自然的不可积结构是**反对称耦合**：cell i 被 cell j 推动，
cell j 被 cell i 反向推动。这类动力学没有极小点，只有**极限环**。

物理含义（这是关键）：

| | 训练的终态 | 极限环的终态 |
|---|---|---|
| 参数 | 不动点，不再变 | 一直动 |
| 可塑性 | 随 η→0 消失 | **永不消失** |
| 早期经历 | 写进终点的位置 | 写进环的**相位** |

如果 ③ 能建在极限环上，A3 与 A5 就不再矛盾：

- **A3（不可逆）** = 环的相位被早期养育锁定，后期改不动
- **A5（还能长）** = 环还在转，永远有可塑性

参数冻结做不到这一点（冻结同时杀死 A5）。**相位锁定不杀死可塑性。**
这是唯一有希望的机制方向。

## 12.5 四次尝试，四次失败（全部记录）

### 尝试 1：加反对称项 `Δw += κ·(Ωw)`

`experiments/e4b_nonconservative.py`

- 非对称度上去了：κ=1e-3 → 3.8e-3，κ=3e-2 → 1.1e-1
- 但**"还在动"是假的**：κ=0 的对照也在动（步长 0.756 vs 0.757）。
  那不是极限环，是恒定 η 的稳态误调抖动。
- 相位记忆 = **0.000**，与对照完全一样。

**失败原因**：`Ωw` 只依赖 `w` 自己，不依赖 `x`、不依赖误差。
它是参数空间的内禀旋转，与环境无关，所以不携带任何信息。

### 尝试 2：加 η 衰减让 κ=0 真停下

`experiments/e4c_fix_confounds.py`

- κ=0 确实停下了（步长 → 8.9e-6），符合预期
- 但 κ>0 **全部发散**：κ=1e-3 就学不会（MSE 0.0083，地板 0.0025），
  κ=0.1 时 MSE ≈ **1e57**

**失败原因**：`Ωw` 是中性项，不衰减、不饱和。η 在衰减，梯度项越来越弱，
旋转项恒定 → 相对越来越强 → 被甩出去。**任何中性项在衰减梯度旁边
最终都会主导。** 这不是参数问题，是结构问题。

### 尝试 3：加振幅限制 `κ·(Ωw)·(1 − |w|²/R²)`

`experiments/e4d_bounded_rotation.py`

- 发散解决了
- 但只有 κ=0.002 一档能同时"学会 + 仍在动"，κ≥0.005 全部学不会
  （MSE 0.008–0.048 vs 地板 0.0025）
- 相位差的 seed 3 出现 `nan`（发散），中位数算不出来

**失败原因**：振幅限制项与梯度项在同一批参数上争夺。κ 大到能产生
可见相位差时，就已经大到破坏学习。**可用的 κ 窗口太窄，窗内信号太弱。**

### 尝试 4（结论）：这三条路都不通，因为它们在同一个 `w` 上加东西

三次失败其实是同一个错误：我把"非保守"当成"在梯度上加一项"。
但加项意味着**梯度与旋转共享同一批参数**，于是必然互相破坏：

- 旋转强 → 破坏学到的 `w` → MSE 上不去
- 旋转弱 → 相位信号淹没在梯度噪声里 → 相位记忆测不出

**这不是调参能解决的问题。要同时"学会"和"永远在动"，
必须让两者作用在不同的量上。**

## 12.6 那么创新的真正入口在哪

从四次失败反推，唯一未被否证的结构是：

> **参数负责学（收敛到 A），结构负责动（永不停止地重组）。
> 两者用不同的自由度，所以不争夺同一个 η。**

这正好是 `docs/09` §11 把 **E4 发育环** 提到 ③ 前面的理由——
不是因为"E4 是下一步"，而是因为**"锁相位"必须先有相位可锁**，
而相位只能存在于结构里（哪些细胞连向哪些），不能存在于参数里
（参数只有一个稳定值 A）。

具体候选（尚未实现，只是设计）：

1. **拓扑持续重组**：细胞之间按局部预测误差建立/断开连接。
   连接图不停变动（这是"动"），但**变动速率**由早期经历决定
   （这是"锁"）。速率是标量，不破坏已学的参数。

2. **细胞身份的相位**：每个细胞有一个内部振荡相位，相位由输入驱动
   （不是由 `w` 自己驱动，这是尝试 1 的教训）。相位差编码"这两个细胞
   看到的是同一个东西"。

3. **可塑性的时间常数分层**：不是 η 的大小分层（那已被证明只是正缩放），
   而是**更新延迟**分层。延迟会让系统出现振荡，而振荡的周期可被
   早期输入锁定。

三条都要求先有"结构"这个概念在代码里。目前没有。

---

## 12.7 一句话结论

> **当前 ③ 就是训练，不是创新。** 数学上可判（非对称度 1e-10），
> 解析上可验（与全局 MSE 梯度差 5.5e-10）。
> 分层、退火、闭锁都只是调度，没有一个让它离开"下山"。
>
> 四次"加非保守项"的尝试全部失败，失败原因是结构性的：
> 梯度与旋转共享同一批参数，必然互毁。
>
> 唯一有希望的方向是让参数学、结构动，两者用不同自由度。
> 这要求 E4 先有代码。**在 E4 有代码之前，③ 不可能变成创新。**
