# ADR-002：训练方式自研条款

- 状态：生效（v2，已否决一版方案）
- 日期：2026-11-26
- 优先级：**高于所有性能目标**（继承 ADR-001 的诚实标注原则）

## 1. 为什么需要这份条款

M2 用了 REINFORCE：折扣回报 G_t、`log π(a|s) × advantage`、对策略反向传播。
它能跑，但有三处过不了本项目的线：

1. **算法归属明确**：REINFORCE 是 Williams 1992；带 baseline 的策略梯度是教科书内容。
2. **与项目主张冲突**：核心主张是"机制自研"。用 30 年前的已知算法训练出的智能体，
   成绩再好也不能证明本项目的假设。
3. **会滑向常规路线**：策略梯度 → actor-critic → PPO → 大模型 RLHF，每一步都有
   现成实现，写着写着就变成调参复现。

自本 ADR 起：**REINFORCE 及其变体只作对照基线，不进主线。**

## 2. 被否决的方案（必须记录）

第一版设计是"三因子局部可塑性"：`ΔW ∝ 前活动 ⊗ 后活动 ⊗ (r − 基线)`，配资格迹。
看似是生物可塑性规则，但展开后：

    对线性 softmax 策略，ΔW ∝ (onehot(a) − p) ⊗ h · δ
    这正是 ∇_W log π(a|s) · advantage

**它是策略梯度的逐项展开，不是另一种机制。** 若以"自研"名义写进报告，
属于改写而非创新。已否决，不留代码。

由此得到一条判据：**只要奖励参与了参数更新，且更新方向是"提高被奖励动作的概率"，
它就是策略梯度**，无论叫赫布、叫资格迹、还是叫局部规则。

## 3. 主线的机制：不给策略任何参数

### 3.1 一句话

孩子**不学怎么行动，只学世界怎么运转**；每次行动都是当场在学到的模型上
**预演**所有可能，按先天驱力挑一个。

代号 **Inner Screen（内屏）**。

### 3.2 两条通道

| 通道 | 学什么 | 训练信号 | 是否有参数 |
|---|---|---|---|
| 世界模型 | (s, a) → s′ | **预测误差**，自监督 | 有 |
| 行动 | 无 | **没有训练信号** | **无参数** |

行动通道没有参数，因此不存在"策略梯度"这种东西：没有可求导的策略，
也没有需要被奖励调制的权重。奖励**完全不进入任何梯度**。

### 3.3 行动是怎么产生的

对当前 s，枚举每个候选动作 a：

1. 世界模型预测 `ŝ′ = f(s, a)`；
2. 先天驱力给 `ŝ′` 打分：
   - 趋近目标：`−‖ŝ′_goal‖`（观测里已有相对坐标）
   - 好奇：`+novelty(ŝ′)`（访问计数稀缺的格子）
   - 省力：预测原地不动则扣分
3. 取分数最高者，带 ε 随机探索。

驱力是**先天的、写死的**，不学习。这是设计选择：价值观不交给梯度去猜。
代价是驱力写错就没有纠错机制，见 §5。

### 3.4 为什么这不等于"常规世界模型 + 规划"

- 常规 model-based RL 仍要学策略或价值函数，奖励进入学习；
  这里**学习阶段一次都没用过奖励**。
- 常规 MoE 的门控是端到端训练的；这里的门控只受**预测误差**驱动，
  与任务成败无关。
- 可验证：把奖励从训练循环里删掉，系统照常工作。这是可执行的实验判据。

### 3.5 与已知方法的关系（诚实标注）

必须写进报告，不得省略：

- **世界模型 + 前向搜索**：Dyna、PILCO、MuZero 系。区别是它们都保留
  策略或价值学习，本项目的行动由写死的驱力决定。
- **内在动机 / 好奇**：Pathak 2017、count-based exploration。本项目借用
  这个概念，但只用于**行动打分**，不用于参数更新。
- **自适应计算 / 规划**：模型预测控制（MPC）。本项目是单步预演，不是长程 rollout。

本项目自研的是组合与归属：预测误差只训练世界模型，驱力只决定行动，
两条通道之间没有梯度通路。**不声称是全新原理。**

### 3.6 允许使用的自研基础设施

- 自研张量引擎与反向传播：**允许用于世界模型**（回归，不是策略）。
- **禁止**：任何让奖励进入参数更新的路径；任何可求导的策略头。

## 4. 验收要求

| 项 | 要求 |
|---|---|
| 合规扫描 | 主线模块中不存在 `log_prob`、`advantage`、`discount` 等策略梯度标识符；命中者必须标 `KNOWN_BASELINE = True` |
| 无奖励训练 | 训练循环中 reward 只写入统计，不进入任何 `backward()` 路径；用测试断言 |
| 对照实验 | 同参数量与 REINFORCE 对比，报告 IQM 与 bootstrap 置信区间 |
| 消融 | 至少三组：随机世界模型（不训练）、去好奇驱力、去目标驱力 |
| 诚实标注 | §3.5 内容必须出现在报告中 |

## 5. 已知风险

1. **驱力写死 = 价值对齐没有学习机制**。目标驱力若写错，孩子会高效地做错事。
   这是有意取舍：把价值放在人手里，而不是交给梯度。
2. **单步预演无长程规划**。需要多步才能获益的任务（推箱入死角）会失败。
   缓解路线见 ADR-003（待写）。
3. **世界模型误差会直接变成行为误差**，没有策略层的纠偏。因此模型质量
   必须单独验收，不能只看任务成功率。
