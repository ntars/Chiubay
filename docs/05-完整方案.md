## 1. 目标与边界

### 1.1 这个项目要交付什么

**一个在本机从零构建、不依赖任何现成 AI 框架与预训练权重、
靠"预测世界"而非"追逐奖励"来变强的智能体机制。**

明确不交付：人级通用能力。本机 128 GiB 统一内存、约 10¹⁴ FLOPS，
人级基座需要 10²³–10²⁶ FLOPs，差 8–10 个数量级。这不是优化问题。

因此"AGI"在本项目中的含义是**机制完备**，不是**能力相当**。判定方式：
每个机制命题都能被实验证伪（见 §2.1）。

### 1.2 硬约束

| 编号 | 约束 | 判定 |
|---|---|---|
| H1 | 全部在本机完成 | 无外部集群、无云训练 |
| H2 | 架构自研 | 不使用 Transformer / MoE / ResNet 等现成结构 |
| H3 | 学习规则自研 | 不使用策略梯度、Q-learning、反向传播训练策略 |
| H4 | 无预训练权重 | 全部随机初始化，从零训练 |
| H5 | 单人、每周约 20 小时 | 排期按此基准 |
| H6 | **诚实标注** | 报告的每个"创新"必须说明最近邻已知方法 |
| H7 | 单模型 <1M 参数（L 层） | `n_parameters()` 断言 |

H6 优先级最高：宁可写"这不是新原理"，也不写"首次提出"。

### 1.3 允许借用的基础设施

张量运算、自动微分、BLAS、Python 运行时属于**计算基础设施**，不是"方案"。
自研的部分是：网络结构、学习规则、决策机制、评估协议。

ADR-001 已记录 BLAS 例外；ADR-002 记录"反向传播仅可用于回归任务"的例外。

## 2. 核心主张

### 2.1 三个可证伪的命题

| 编号 | 命题 | 证伪方式 |
|---|---|---|
| P1 | 只靠"预测下一步"，就能支撑目标导向行为 | 世界模型精度达标但成功率不达标 |
| P2 | 行为提升完全来自模型精度，不来自任何策略学习 | 冻结模型后行为不随训练提升（应如此） |
| P3 | 专家分化可由"预测难度差异"自发产生，无需标签监督 | 预测误差均匀时仍出现分化，或反之 |

三条全部通过 → 机制成立。任一失败 → 如实记录失败原因，不掩盖。

### 2.2 与"常规训练 AI"的分界线

| 维度 | 常规做法 | 本项目 |
|---|---|---|
| 学习信号 | 奖励 / 标签 / 下一 token | **只有预测误差** |
| 策略 | 参数化，用梯度训练 | **无参数，现场预演** |
| 价值函数 | 学习得到 | **不存在** |
| 奖励的作用 | 驱动参数更新 | **只用于评估，不进梯度** |
| 门控 | 端到端训练 | 只受预测误差影响 |
| 目标 | 最大化期望回报 | 满足先天驱力 |

**最关键的一条**：把训练循环里的 `reward` 全部置零，系统必须照常工作。
这是一个可执行的测试，不是口号。

## 3. 总体架构

```
            ┌─────────────────────────────────────────┐
            │  内屏 Inner Screen（决策，无参数）        │
            │                                         │
   观测 s ──► 枚举 5 个候选动作 a                     │
            │   ├─► 世界模型 f(s,a) ─► ŝ′             │
            │   └─► 驱力 D(ŝ′) ─► 分数                │
            │   选 argmax，ε 概率随机                  │
            └───────────────┬─────────────────────────┘
                            │ a
                            ▼
            ┌───────────────────────────────┐
            │  沙盒 GridWorld（自研）        │
            └───────────────┬───────────────┘
                            │ s′, r
                            ▼
            ┌───────────────────────────────┐
            │  世界模型（唯一被训练的部分）   │
            │  LSE 主干 + 差分预测头          │
            │  损失 = ‖f(s,a) − (s′−s)‖²     │
            └───────────────────────────────┘
```

三类部件：

| 部件 | 参数 | 训练 | 作用 |
|---|---|---|---|
| 世界模型 | 有 | 预测误差 | 学"世界怎么运转" |
| 驱力 | **无** | **不训练** | 定义"想要什么" |
| 内屏 | **无** | **不训练** | 用模型预演并选择 |

## 4. 学习机制（自研核心）

### 4.1 为什么不用策略梯度

任何"提高被奖励动作概率"的更新，无论写成
`log π(a|s)·G`、`(onehot − p)·δ`、还是"三因子赫布规则"，数学上是同一件事。
换个名字不构成自研。ADR-002 §2 记录了这条方案被否决的过程。

要真正不同，必须让**奖励不进入任何参数更新**。唯一干净的做法是：
不参数化策略。

### 4.2 Inner Screen 的三步

**第一步：预演。** 对当前观测 s，为每个候选动作 a 构造输入 `(s, a)`，
用世界模型预测 `ŝ′ = s + f(s, a)`。

**第二步：打分。** 先天驱力 D 给每个 ŝ′ 打分：

    D(ŝ′) = w_goal · (−d(ŝ′, goal))
          + w_novel · novelty(ŝ′)
          − w_still · 1[ŝ′_pos == s_pos]

- `d(·, goal)`：用观测里已有的相对坐标 `(gx−ax, gy−ay)` 计算，不需额外监督。
- `novelty`：格子访问计数的倒数，`1/√(1+n)`。鼓励去没去过的地方。
- `still`：预测原地不动说明前方被挡，扣分，避免撞墙循环。

**第三步：选择。** `a = argmax D`，以概率 ε 随机。ε 随训练线性衰减。

三段都**没有可训练参数**，因此不存在策略梯度。

### 4.3 世界模型规格

| 项 | 规格 |
|---|---|
| 输入 | `obs(16) ⊕ onehot(action)(5)` = 21 维 |
| 输出 | `Δs`（16 维差分） |
| 主干 | LSE：8 专家 × 32 维，Top-2 门控，无联动桥 |
| 损失 | MSE(`f(s,a)`, `s′−s`) |
| 优化 | 自研 Adam，lr 2e-3 |
| 参数 | 约 6.3k（L 层上限 1M 的 0.6%） |
| 训练方式 | 回放缓冲采样 minibatch，纯回归 |

**为什么预测差分**：多数维度每步只动一格，绝对值的方差远大于差分；
直接回归绝对值会把容量浪费在拟合常量上。

**为什么用 LSE 而不是普通 MLP**：LSE 的门控会按输入把工作分给不同专家。
若不同区域的预测难度不同（近墙 vs 空旷），门控应当自发分化——这正是 P3 要检验的。

### 4.4 驱力规格（写死，不学习）

| 驱力 | 公式 | 权重 | 设计意图 |
|---|---|---|---|
| 趋近目标 | `−‖(gx,gy) − (ax,ay)‖ / diag` | 1.0 | 唯一的"目标"来源 |
| 好奇 | `1/√(1+count[cell])` | 0.15 | 打破局部最优、覆盖地图 |
| 省力 | `−1[预测位置不变]` | 0.3 | 抑制撞墙 |

**这是价值判断，不是学习结果。** 有意为之：价值观留在人手里。
代价见 §10 风险 1。

### 4.5 无奖励判据（可执行）

```python
# 训练循环中 reward 只出现在统计里
loss = model.train_batch(obs, act, next_obs)   # 签名里没有 reward
```
测试断言：`train_batch` 的入参不含奖励；把 `env.step` 的奖励全部置零，
成功率变化 < 5 个百分点。

### 4.6 已否决：三因子局部可塑性

曾设计 `ΔW ∝ 前活动 ⊗ 后活动 ⊗ (r − 基线)` 配资格迹，作为"生物可塑性规则"。
展开后对线性 softmax 策略恰好等于策略梯度，属改名而非创新，已否决（ADR-002 §2）。

## 5. 发育阶段

阶段不是"训练轮数"，是**能力门槛**。每阶段有独立的退场条件，不达标不进入下一阶段。

| 阶段 | 环境 | 要长出的能力 | 驱力配置 | 退场条件 |
|---|---|---|---|---|
| **S0** | 8×8 网格，3 障碍 | 单步预演导航 | 目标 + 省力 | 成功率 ≥85%，5 seeds |
| **S1** | 8×8 + 可推箱 | 预测"动作改变世界"（推箱） | + 好奇 | 推箱到位率 ≥60% |
| **S2** | 12×12 + 多房间 | 多步预演（深度 3–5） | 同上 | 跨房间任务 ≥50% |
| **S3** | 加入颜色/形状指令 | 语言指令 → 目标重定向 | + 指令跟随 | 未见组合 ≥80% |
| **S4** | 双智能体 | 预测他者的预测（社交） | + 模仿 | 协作任务 ≥50% |
| **S5** | 自我修改 | 改自己的驱力权重/结构 | 元驱力 | 修改成功率 ≥50%，可回滚 |

S0–S1 在本机数月内可完成；S2 起每级都需要新的机制，不是调参。

## 6. 预演深度演进

单步预演无法处理"必须先远离目标才能到达"的任务。演进路线：

| 版本 | 机制 | 计算成本 | 解决什么 |
|---|---|---|---|
| **P0**（当前） | 单步，枚举 5 动作 | 5×前向/步 | S0 导航 |
| **P1** | 深度 2–3 的贪心展开 + 剪枝 | 25–125×前向/步 | 绕障、S1 推箱 |
| **P2** | 束搜索 + 好奇心加权 | 可控 | S2 多房间 |
| **P3** | 学到的"预演策略"决定展开哪里 | 待定 | 大规模场景 |

P1 起必须解决"模型误差随深度累积"：预测 3 步后的状态误差约为单步的 3 倍，
需要在预演中按不确定性折扣。

## 7. 评估体系

### 7.1 三层指标（缺一不可）

| 层 | 指标 | 门槛 | 说明 |
|---|---|---|---|
| **模型层** | 单步位置 MAE | < 0.02（归一化单位，约 1/8 格） | held-out 转移 |
| | 阻挡预测准确率 | > 90% | 预测"撞墙后位置不变" |
| **行为层** | 成功率 | ≥ 85% | 20 episodes × 5 seeds |
| | 平均步数 | 接近最短路 ×1.5 | 效率，不是只看成功 |
| **机制层** | 路由增益 routing_gain | > 0.1 | 世界模型门控 |
| | 死专家数 | ≤ N/4 | 8 专家最多死 2 个 |

**只看成功率是不够的**：可能模型很差但驱力碰巧能兜住。三层同时看，
才能区分"真学会了"和"运气好"。

### 7.2 统计口径（已修正）

- 5 个 seed 起步。
- 报告 **IQM**（去掉最高/最低各 25% 的均值）与 **bootstrap 95% 置信区间**。
- 上一轮 `m2_s0.py` 的 `iqm()` 取的是最低 25% 均值，是错的，已修为
  `src/child/stats.py`。旧报告里的 `IQM=-0.021` 作废。
- 均值 ± 标准差不足以说明问题，必须给区间。

### 7.3 验收门

| 门 | 条件 | 当前状态 |
|---|---|---|
| **G0** | S0 成功率 ≥85%（IQM，CI 下界 ≥0.75）；模型 MAE <0.02；无奖励判据通过；5 seeds | 未开始（REINFORCE 版不计入） |
| **G1** | S1 推箱 ≥60%；预演深度 ≥3；旧任务遗忘 <10% | 未开始 |
| **G2** | 语言指令未见组合 ≥80%；序列模块消融下降 >20% | 未开始 |
| **G3** | 自我修改成功率 ≥50%，回滚 100% | 未开始 |

### 7.4 消融矩阵（G0 必需）

| 配置 | 改动 | 检验什么 |
|---|---|---|
| `full` | 完整 Inner Screen | — |
| `random_model` | 世界模型不训练 | P2：行为是否退化到随机 |
| `no_goal` | 去目标驱力 | 驱力是否真的在起作用 |
| `no_novelty` | 去好奇驱力 | 好奇是否必要 |

`oracle_model` 最关键：如果 oracle 也只到 70%，说明瓶颈在驱力设计，不在学习。

## 9. 风险与停止条件

| 风险 | 概率 | 应对 |
|---|---|---|
| 单步预演无法绕障，成功率卡在 60% | 中 | 升级 P1 深度预演；`oracle_model` 判断瓶颈位置 |
| 模型误差累积，深度预演反而更差 | 中 | 预演按不确定性折扣；限制深度 ≤3 |
| 驱力写死导致"高效做错事" | 高 | 这是有意取舍；S5 才引入自我修改 |
| 专家始终不分化 | 中 | 若预测误差天然均匀，P3 被证伪，如实报告 |
| 无奖励训练导致探索不足 | 中 | 好奇驱力 + ε 衰减；不够则加计数型内在奖励（仅用于打分） |

**停止条件**（触发即停下重审，不硬推）：

1. S0 在 3 个月内未达 85%，且 `oracle_model` 也未达 → 驱力设计有根本缺陷。
2. P2 被证伪（冻结模型后行为仍在提升）→ 说明有未识别的学习通道，机制描述不实。
3. 为达标而引入策略梯度或价值函数 → 直接违反 H3，项目性质改变。

## 10. 与已知方法的边界（诚实标注）

必须出现在最终报告中，措辞不得弱化：

| 本项目 | 最近邻已知方法 | 差异 |
|---|---|---|
| 世界模型 + 前向预演 | Dyna、PILCO、MuZero | 它们保留策略/价值学习；本项目行动由写死驱力决定，无策略参数 |
| 好奇心驱力 | Pathak 2017、count-based exploration | 本项目只用于**打分**，不用于参数更新 |
| 单步模型预测控制 | MPC | 本项目是单步枚举，不是长程 rollout |
| LSE 专家门控 | MoE、Switch Transformer | 门控只受预测误差驱动，不与任务奖励耦合 |
| 差分预测 | 残差预测、Δ 学习 | 常规技巧，非创新 |

**不声称任何一项是全新原理。** 本项目的贡献在于组合与归属：
预测误差只训练世界模型，驱力只决定行动，两条通道之间没有梯度通路。
这个"没有通路"是可测的，也是唯一值得写进结论的东西。
