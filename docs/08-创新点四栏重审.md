## 1. 创新点 A：树突分室 → `CONVENTIONAL`

### 四栏

| 栏 | 内容 |
|---|---|
| **N** 最近邻 | 分层预测编码（Rao & Ballard 1999）；多头注意力（Vaswani 2017）；稀疏编码（Olshausen & Field 1996） |
| **D** 机制差别 | **填不出。** 分室 = 不同感受野的子单元；逐分室局部误差 = 预测编码的误差单元；增益 `a_b` = 注意力权重。三者都是原方法已有的 |
| **M** 可测后果 | **无。** 唯一可能的差别是"增益受调制向量控制"，但那是创新点 B 的内容，不是 A 的 |
| **A** 消融 | 分室数 1 vs N：预计有性能差异，但该差异**由参数量与容量解释**，不构成机制差别 |

### 判定：`CONVENTIONAL`

**处理方式：**

1. 从创新章节移除，移入"工具层"。
2. **但仍保留实现**，理由：它是有用的工程结构（多感受野 + 局部误差），
   能让系统在同等参数下表达更丰富。保留不构成创新声明。
3. 报告中不得出现"树突分室是创新"的表述。若需提及，写
   "采用多感受野子单元结构（预测编码式），非本项目创新"。

### 什么时候可以翻案

若能做到下面任一条，可重新提为创新：

- 分室的**时间常数不同**（快/慢分室），且证明快慢分离带来**无法用
  单一时间常数复现**的行为。这是可测的：把系统换成统一时间常数，
  若行为完全一致，则时间常数不是机制。
- 分室之间有**非加性的相互作用**（例如分室间通过局部场耦合，
  而非简单求和）。这需要偏出"求和"这个结构，目前方案没有。

**结论：A 目前是常规件。这一条我必须承认，不能靠措辞绕过。**

## 2. 创新点 B：调制向量 → 保留，但改为"规则切换"

### 四栏

| 栏 | 内容 |
|---|---|
| **N** 最近邻 | 神经调制（Doya 2002）；元学习（MAML, Finn 2017）；门控网络（Hochreiter 1997） |
| **D** 机制差别 | 关键不在"向量 vs 标量"，在**它作用于什么**：<br>• 神经调制 / 元学习：调**参数更新的幅度或方向**（学习率、初始化）<br>• 本项目：调**哪一条可塑性规则生效**（`Δw = Σ m_k R_k`），规则本身形式不同 |
| **M** 可测后果 | 把 `m` 固定为常数（等价单一规则）→ 若性能不变，说明"切换"没有发生，只是加权平均。**这是一个能杀死该创新点的实验** |
| **A** 消融 | E3：`m` 常数 vs `m` 变化。指标：在不同环境统计下的适应速度 |

### 判定：保留（`INNOVATIVE`，强度：中）

**但必须修正 06 号的表述。** 06 号写"调制向量不是奖励标量"，
这个对比是**误导**的：奖励标量之所以是标量，是因为 RL 只需要"好/坏"；
本项目用向量，是因为要做四件事。**这不是创新，这是需求不同。**

真正的创新点是：**`m` 不进梯度，只选择规则。** 这一点可测、可证伪。

**必须补的实验：**

| 实验 | 操作 | 若结果相反 |
|---|---|---|
| E3a | `m` 固定为常数 | 性能不变 → 退化为单规则，B 作废 |
| E3b | `m` 随机（不来自环境统计） | 性能与 E3a 相同 → `m` 只是噪声，作废 |
| E3c | `m` 只保留一维（如只留误差） | 性能接近完整 → 其余三维是装饰，删 |

## 3. 创新点 C：父母示范用于建模 → 保留（最强）

### 四栏

| 栏 | 内容 |
|---|---|
| **N** 最近邻 | 行为克隆（Pomerleau 1989）；逆模型学习；DAgger（Ross 2011）；逆强化学习（Ng & Russell 2000） |
| **D** 机制差别 | 克隆学 `s → a`；IRL 从示范**推断奖励**；本项目学 `(s,a) → s′`，**不推断奖励，也不学动作**。示范只提供"这个动作会导致什么"的因果数据 |
| **M** 可测后果 | **给次优父母（30% 动作是随机的）**：<br>• 克隆：性能被拖到 ≈70%<br>• 本项目：若模型能识别"该动作未产生通常效果"，性能不受影响<br>**这是全项目最干净的一个判据**，因为它有明确的失败预测 |
| **A** 消融 | E1：克隆 vs 建模。指标：次优父母下的最终性能 |

### 判定：保留（`INNOVATIVE`，强度：中偏强）

**为什么这条最强**：它有一个**反直觉的预测**——错误的示范可能让本系统
**更好**（提供了反例信息），而克隆一定更差。反直觉预测比"我们更好"
这种声明有力得多。

**风险（必须写进报告）：** 若次优父母下两者性能相同，说明本系统
实际上还是在克隆，只是包装不同。**这个失败模式必须在实验前列出，
不能事后解释。**

## 4. 创新点 D：自读触发分裂 → 保留

### 四栏

| 栏 | 内容 |
|---|---|
| **N** 最近邻 | NEAT（Stanley 2002）；MoE（Shazeer 2017）；元学习；自监督预测（Schmidhuber 1991） |
| **D** 机制差别 | • NEAT：**全局适应度**选择拓扑<br>• MoE：专家数**固定**<br>• 本项目：触发信号是**自读一致性**（我能否预测我自己的下一步），纯局部，无适应度、无固定专家数 |
| **M** 可测后果 | **无任务环境中仍应发生分裂。** 给纯随机扰动环境（无任何可优化目标），<br>NEAT 无法定义适应度，本项目应仍能发育。可测：细胞数增长曲线 |
| **A** 消融 | E4：关自读（不触发分裂）。指标：结构复杂度、行为多样性 |

### 判定：保留（`INNOVATIVE`，强度：中）

**关键论证在 M 栏**：这个实验设计让"没有全局损失"从口号变成
**结构上的不可能**——没有适应度就无法做进化选择。这比"我们没有用 loss"
这种声明强得多，因为它给出了一个 NEAT 做不到的具体场景。

**但有一个隐藏依赖：** 若 §5 的"三环"没有真正解耦（例如分裂阈值实际上
由某个全局量调节），D 就退化为"带局部触发的剪枝"，届时作废。

## 6. 这一轮暴露的方法论问题

A 之所以能从"创新点"降为"常规件"，是因为四栏标准要求**填出机制差别**。
06 号方案写"分室感受野不同"时，我没有追问"那和多头有什么不同"。

**这说明一个可复用的检查方法**：对每个创新点问

> "如果我只改这一处，把它换成最近邻方法，实验会有什么不同？"

答不出具体差异 → 该处不是创新，是命名。

这条检查比四栏更狠，因为它要求**反事实**。建议纳入 §1 作为第 5 栏（**C 栏：反事实**）。
