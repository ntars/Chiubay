# 玖白 · 两周期架构 v4.3

> 本文取代 `docs/07`、`docs/08` 的地基部分，是当前唯一权威架构文档。
> 触发条件：用户明确"项目分两个周期，第一个是婴儿，第二个是完全体"，
> 并明确"最终目的不是创造完全体，而是一个刚出生的婴儿，不同教育方式
> 会让它变成不同的完全体"。
>
> **这句话把验收标准整个换掉了。** 若交付物是婴儿，那么"会不会做事"
> 不是判据，"会不会被养成"才是。前者可被任何 RL 系统冒充，后者不能。
>
> **v4.2 变更（2026-11-27）**：E3 v1/v2 **连同 v4.1 的降级理由**一并作废。
> 原因不是参数没调好，是**学习规则本身是坏的**：
> `Δw = η·(w·dx)·x/|x|²` 的不动点是 `w=0`（实测 20000 步后 `‖w‖=2.4e-28`），
> 前三版测到的"印记"全是权重崩塌途中的残留量。
> 换预测式 LMS 后装置有效（预测 MSE 0.00252 ≈ 噪声地板 0.00250）。
>
> **v4.2 第四轮追加（同日）**：装置修好后发现指标还没信噪比，又把
> `d` 降到 12、`amp` 提到 2.5、`gamma` 提到 2.0，S/N 从 0.50 升到 **1.70**，
> 指标第一次能分辨养育信号（理想 MLE 印记 +0.78 ~ +0.85，说明**实验设计没问题**）。
>
> **v4.2 第五轮（同日，再改判）**：第四轮那句"闭锁与学习差 20–100 倍"
> **是错的，已撤回**。我把 LMS 的**稳态误调地板**误读成了"学习很慢"：
> 恒定 η=0.30 时 `‖W−A‖/‖A‖` 在 500→30000 步始终停在 0.39–0.45，
> 加步数**不下降**（这是 `η·tr(R)/2`，与步数无关）；η 一衰减，
> **2000 步就到 0.111**。那个时间尺度冲突不存在。
> 同时发现 A3 的旧测量**混淆了剂量与巩固时间**（早期窗口后还有 25,700 步
> 可恢复，晚期只剩 800 步），旧的 0.0057 无意义。
> 改用等剂量 + 等巩固后：**A3 可以成立**（晚/早 0.022–0.055，判据 0.20），
> 但 **A3 与 A5 在同一个 seed 上同时成立只有 3/10**——两个指标各自都有
> 60–70% 通过率，却不在同一次运行里一起通过，属边界抖动而非机制。
> ③ 维持 `PENDING`，理由第四次改变：
> "参数没调好" → "装置坏了" → "指标没信噪比" → "闭锁与学习冲突"（数字错）
> → **"A3 可实现，但 A5 被同一机制削弱，二者不可靠并存"**。
>
> **v4.3 变更（2026-11-27，最重要的一次）**：用户问"确定这和训练 AI 大模型
> 不一样吗，我要的是创新"。用雅可比对称性做判决，答案是**不一样是假的**：
> 更新场非对称度 = **1.1e-10**，即它是 `L = mean(‖y−Wx‖²)` 的精确负梯度
> （解析与数值梯度差 5.5e-10）。**③ 的实质是"一层线性回归 + SGD +
> 学习率退火 + 冻结表"，Widrow–Hoff 1960。**
> 分层、退火、闭锁都只是逐坐标正缩放，没有一个让它离开"训练"。
> 四次想制造"非训练"性质的改造（反对称耦合、η 衰减、振幅限制）全部失败，
> 原因结构性：梯度与旋转共享同一批参数，必然互毁。
> ③ 的判定从 `PENDING` 改为 **`CONVENTIONAL`**；② 的"无全局损失"表述撤回。
> 详见新增的 **`docs/11-与训练的边界.md`**。
>
> §1–§3 的架构主张未变；§5 ②③④、§6 第 4/5 行、§7、§8、§10、§11 已按新数据改写。

## 0. 你的这句话改变了什么

前三版方案（05/06/07）都在追同一个东西：一个**能完成任务**的系统。
只要目标还是"能完成任务"，评价就必然落回成功率，架构就必然向
"更强的函数逼近器"收敛，最后一定做成一个小号 Transformer。

你这句话把它拆成了两段，而且两段的判据完全不同：

| | 周期一：婴儿 | 周期二：完全体 |
|---|---|---|
| **是什么** | 一个**可被塑造的初始结构** | 被某种养育方式**塑造出的结果** |
| **判据** | 可塑性、敏感期、结构可生长 | 该形态下能维持自身存续 |
| **谁决定** | 环境与养育者 | 婴儿期的经历 + 后续自我维持 |
| **能否重来** | 能（换一个婴儿） | 不能（同一婴儿只有一种成年形态） |
| **本项目是否交付** | ✅ 这是交付物 | ❌ 这是**产物**，不是交付物 |

这句话的分量在于：**它让"不完美"变成了正确。** 一个婴儿不会做事，
这是正常的，不是失败。反过来，任何"一出生就会做事"的东西都不是婴儿，
是成品——而成品不需要养育，也就证明不了"养育"这件事有效。

于是整个项目的核心命题变成一句可证伪的话：

> **同一个初始结构，在不同养育方式下，会长成可测量的不同成年形态；
> 且这种差异一旦形成，就不能被后期训练抹平。**

**这句话是全文的地基。** 下面六环全部是为了让它可测而存在的。
如果这条命题测不出来，六环再精巧也只是装饰。

## 1. 为什么必须是"六环"，而不是"六个模块"

模块可以任意拆分组合，环不行。环的定义是：**去掉任何一个，其余全部失效。**
这是"环环相扣"的可检验含义——不是"我设计了六个东西"，而是
"我证明这六个互为前提"。

```
                        ┌──────────────────┐
                        │  ⑥ 代谢环         │  维持自身有成本
                        │  无寿命，但会"饿"  │  → 目标从内部产生
                        └────────┬─────────┘
                                 │ 成本压力决定"什么值得学"
                                 ▼
   ┌────────────────┐    ┌──────────────────┐    ┌────────────────┐
   │ ① 身体环        │───▶│ ② 耦合环          │───▶│ ③ 认同环        │
   │ 有限细胞、有限   │    │ 读写两条通道      │    │ 棘轮+锚点       │
   │ 活动预算        │    │ 无obs/action/reward│   │ → 敏感期        │
   └────────────────┘    └──────────────────┘    └────────┬───────┘
            ▲                                             │ 锁定
            │                                             ▼
   ┌────────────────┐    ┌──────────────────┐    ┌────────────────┐
   │ ⑥ 代谢环        │◀───│ ⑤ 教育环          │◀───│ ④ 发育环        │
   │ （闭环回到①）    │    │ 父母只塑形环境     │    │ 分裂/修剪/迁移  │
   └────────────────┘    └──────────────────┘    └────────────────┘
```

**六条依赖，每条都是"去掉它，下游失效"：**

| 去掉 | 直接后果 | 连锁后果 |
|---|---|---|
| ① 身体（有限预算） | 细胞无限增殖 | 没有取舍，就没有"重要性"，发育退化为均匀铺满 |
| ② 耦合（读写通道） | 退回 obs/action 接口 | 立刻可被 RL 算法覆盖，③④⑤ 全部失去意义 |
| ③ 认同（棘轮） | 可塑性恒定 | 早期经历被后期抹平，**两周期命题直接不成立** |
| ④ 发育（结构变化） | 结构固定 | 认同无物可锁，"成年形态"不存在，只剩参数差异 |
| ⑤ 教育（环境塑形） | 只有一个环境 | 无法比较不同养育，命题不可测 |
| ⑥ 代谢（维持成本） | 无内部压力 | 目标只能外部给定，系统退回"任务执行器" |

**注意 ③ 的位置**：它卡在中间。没有它，①②只是"一个传感器 + 一个身体"；
有了它，④才产生**不可逆**的结构，⑤才产生**持久**的影响，⑥才有
"维持一个已经成型的东西"这件事可谈。整条链的因果都从 ③ 穿过。

这就是为什么上一版把"树突分室"当创新点是错的：分室在 ① 层，
它再精巧也只是感受野设计，动不了因果链。**创新的位置比创新的精巧程度重要。**

## 2. 周期一：婴儿

### 2.1 婴儿的定义（可检验，不是比喻）

一个系统是"婴儿"，当且仅当同时满足：

| # | 条件 | 检验 |
|---|---|---|
| I1 | **结构未定**：细胞数与连接拓扑在发育中改变 | 记录分裂/修剪事件数 > 0 |
| I2 | **能力为空**：初始状态下不完成任何任务 | 初始成功率 = 随机水平（不设任务时：无"成功率"概念） |
| I3 | **可被塑造**：不同早期环境产生不同结构 | 两个环境 → 结构距离 > 噪声底 3 倍 |
| I4 | **不可预编程**：没有任何模块编码"该做什么" | 静态扫描：无 policy / 无 action space / 无 reward |
| I5 | **有认同**：早期形成的东西后期难以覆盖 | 敏感期实验：早期印记残留 >> 晚期 |

**I2 是最容易被违反的一条。** 只要给婴儿任何任务，它就不是婴儿了，
它是"会做那个任务的成品"。这是本项目最容易走偏的地方，必须写死。

### 2.2 婴儿期做什么（只有三件事）

婴儿期**不训练任何能力**。只发生三件事，全部由局部量触发：

```
1. 长身体：细胞分裂（局部预测误差持续高 → 一分为二）
2. 认世界：局部可塑性收敛（每个细胞学会预测自己收到什么）
3. 定性格：认同棘轮闭合（载荷累积 → 学习率下降 → 窗口关闭）
```

三件事没有先后，是同一个过程的三面。**"定性格"是不可逆的那一面**，
它让前两件事的结果固定下来，成为周期二的起点。

### 2.3 婴儿期结束的标志

不是"学会了什么"，而是：**可塑性降到阈值以下，且结构事件停止。**

```
结束条件（全部满足）：
  mean(η_eff) < η0 × 0.1
  最近 1000 步内分裂事件 = 0
  最近 1000 步内修剪事件 = 0
```

这个条件由系统自己满足，不由时钟决定。**不同的婴儿会在不同时间结束**，
这本身就是个体差异的第一层来源。

## 3. 周期二：完全体

### 3.1 完全体不是目标，是分歧点

这里必须说清一件反直觉的事：

> **"完全体"不是一个要达到的状态，是一个要被观察的结果。**

就像人的成年不是"完成"，而是"定型"。我们不需要设计完全体，
只需要保证：婴儿期结束后，系统仍然能维持自身（不崩溃、不退化），
并且带着婴儿期的烙印继续存在。

因此周期二的判据不是"能力多强"，而是：

| # | 判据 | 检验 |
|---|---|---|
| A1 | **存续**：长期运行不崩溃、不发散 | 10⁶ 步无发散；活动量有界 |
| A2 | **带烙印**：成年形态保留婴儿期环境的结构特征 | 结构特征与婴儿期环境的相关性 > 阈值 |
| A3 | **不可逆**：后期环境无法抹平烙印 | 晚期暴露后，结构距离变化 < 早期效应的 20% |
| A4 | **可分化**：不同养育 → 可测量的不同成年形态 | 多环境矩阵，成年形态聚类与环境一一对应 |
| A5 | **无上限**：结构仍可缓慢生长（不断臂） | 长期运行中仍有低频分裂事件 |

**A3 和 A5 是一对矛盾**，必须同时成立：既要"烙印抹不掉"，又要"还能长"。
解法是把可塑性分层——**认同层冻结，外围层保留**（见 §4.3）。
这一对矛盾如果解决不了，"无上限、无寿命"就只是口号。

### 3.2 "无寿命"的真实含义

无寿命不是"永远不死"，是**没有预设的终止条件**。系统不会因为
"训练结束"而停止，只会因为维持不住而退化——而退化本身是
可观测的（活动量下降、结构萎缩）。

所以"无寿命"的可检验形式是：

```
不存在 termination 变量；
不存在 max_steps；
系统的结束只有一种：维持不住（可观测的退化过程，不是二值事件）
```

## 4. 教育方式如何决定完全体（三个旋钮）

这是"不同教育 → 不同完全体"的具体机制。只有三个旋钮，全部作用在**环境**上，
不作用于孩子。

### 4.1 旋钮一：结构规律性（决定"能看见什么"）

| 设置 | 环境特征 | 预期成年形态 |
|---|---|---|
| 高规律 | 输入维度强相关、有重复几何 | 少量大感受野细胞，长程连接 |
| 低规律 | 各维独立、白噪声为主 | 多量小感受野细胞，局部连接 |
| 突变 | 规律中途改变 | 结构分层，边界处细胞密集 |

**不作用于孩子**：父母不告诉孩子"这里有规律"，只让世界真的更有规律。

### 4.2 旋钮二：可及范围（决定"能碰到什么"）

父母把物体放在孩子当前能力可及的位置，并随发育扩大范围。
不放在够不到的地方（那会产生持续失败），也不一直放在原地（那不产生新结构）。

这条对应"最近发展区"（Vygotsky 1930s），但**只借概念，不借实现**：
实现是"改变环境的物理距离"，不是"调整任务难度"。

### 4.3 旋钮三：扰动时机（决定"什么时候定型"）

| 时机 | 效果 |
|---|---|
| 早期扰动 | 被棘轮锁住 → 成为永久特征（印记） |
| 晚期扰动 | 被阻抗门挡住 → 几乎无影响 |
| 全程扰动 | 结构不稳定 → 发育延迟或碎片化 |

**这是"敏感期"的工程实现**，也是两周期命题的核心机制。它必须由
载荷累积**自发**产生，不能由外部时钟控制——否则就是"预设课程表"，
不是发育。

## 5. 六环的创新审计（按 v3.0 四栏标准）

标准沿用 `docs/07` §1：N 最近邻 / D 机制差别 / M 可测后果 / A 消融。
任一栏填不出即降级。**这次我不给"中/强"评分，只给判定。**

### ① 身体环：有限活动预算

| 栏 | 内容 |
|---|---|
| **N** | 稀疏编码的容量约束（Olshausen & Field 1996）；代谢约束下的神经网络（Laughlin 2001，能量预算） |
| **D** | 他们的预算约束作用在**单个神经元的发放率**上；本项目作用在**细胞群的总活动量**上，且预算**随存续时间累积消耗**（不可再生），因此"用掉的机会"变成稀缺资源，而非每步固定成本 |
| **M** | 若预算真是稀缺且累积的，则**同一环境、预算越紧，细胞分工越专一**（感受野方差增大）。可测：预算 ×3，感受野重叠度应上升 |
| **A** | 去掉预算（无限），结构均匀铺满，分化度下降到接近 0 |
| **判定** | `INNOVATIVE`（弱—中）：差别是"累积不可再生"这一条，不是"有预算" |

**诚实说明**：能量约束是神经科学老话题。本环的可辩护点只有一条：
**"预算不可再生"使系统产生"用掉就没了"的时间压力**，这不同于每步固定的
发放成本。若这条在实验里测不出（E1），本环降为 `CONVENTIONAL`。

### ② 耦合环：读写两条通道，无 obs/action/reward

| 栏 | 内容 |
|---|---|
| **N** | 动力系统取向认知科学（Beer 1995；Thelen & Smith 1994）；形态计算（Pfeifer & Bongard 2006）；BCI 的读出/刺激结构 |
| **D** | 他们描述现象或建小模型；本项目把**读写耦合当作唯一接口并作为硬约束**，使 `π(a|s)` 在系统内不存在（不是被禁用，是无定义） |
| **M** | 若接口真被取消，**任何需要 (S,A,R) 的算法都无法直接套用**。可测：尝试接入 REINFORCE 会在类型层面失败（无 action space） |
| **A** | 对照：同一结构换成显式 obs/action 接口，行为多样性下降多少 |
| **判定** | `INNOVATIVE`（中）：差别在工程归属而非科学发现，但后果硬 |

> **⚠️ 这一栏曾被我当成"创新"来辩护，是错的。** 见 `docs/11` §12.2。
>
> "没有 obs/action/reward"只说明**接口形状不同**，不等于**没有目标函数**。
> 实测：当前 ③ 的预测式 LMS 更新场雅可比非对称度 = **1.1e-10**，
> 即它是 `L = mean(‖y − Wx‖²)` 的**精确负梯度**（解析式与数值梯度
> 相对差 5.5e-10）。
>
> **所以"无 reward"是真的，"无目标"是假的。MSE 就是目标。**
> 取消 `π(a|s)` 使 RL 算法套不进来，这条成立；但把一个监督学习目标
> 藏进"预测误差"里，并不构成与训练的本质区别。
>
> ② 的 `INNOVATIVE` 判定可以保留（接口改造确实有工程后果），
> 但**不得再用来暗示"这不是训练"**。判据与四次失败记录见 `docs/11`。

### ③ 认同环：收敛比棘轮 + 锚点钉住 + 可塑性分层

| 栏 | 内容 |
|---|---|
| **N** | 关键期 / 印记（Lorenz 1935；Hubel & Wiesel 1970）；突触巩固与"可塑性即稳定性"（Fusi 2005，级联模型）；弹性权重巩固 EWC（Kirkpatrick 2017）；LMS 的步长衰减消除误调（Robbins–Monro 1951；Widrow–Hoff 1960） |
| **D** | EWC 用 Fisher 信息（由全局损失导出）决定哪些参数该保护；本环用**逐细胞的预测收敛比** `conv_i = \|err_i\| / \|err_i(出生)\|` 驱动。<br>**⚠️ "无全局量参与"这句话在 v4.3 被证伪**：逐细胞梯度精确等于全局 MSE 的梯度（`docs/11` §12.2）。局部性只指"梯度可逐坐标算"，不是"不存在全局目标" |
| **M** | 若锁定真由收敛比驱动，则**无任务的随机环境里也会锁定**（EWC 无法在此定义 Fisher）。可测：纯预测任务下已实测 η 由 0.30 降至 2e-3，预测 MSE 0.00252 ≈ 噪声地板 0.00250 |
| **A** | 已做，结果见下 |
| **判定** | **`CONVENTIONAL`（v4.3 改判，不再是 `PENDING`）** |

**v4.3 的改判：从"没验证通过"改为"验证通过了也不是创新"**

前几版把它标成 `PENDING`，暗示"等一个实验就能定性"。这是错的。
`docs/11` 给出了数学判决：

- 更新场雅可比非对称度 = **1.1e-10** → 它是 `L = mean(‖y−Wx‖²)` 的精确负梯度
- 解析梯度与数值梯度相对差 = **5.5e-10**
- 逐细胞不同 η（可塑性分层）→ 非对称度仍 1e-10（正缩放不改变场的性质）
- η→0（闭锁）→ 非对称度 0（退化梯度场）

所以 ③ = **一层线性回归 + SGD + 学习率退火 + 冻结表**。
Widrow–Hoff 1960。机制本身属 `CONVENTIONAL`。

**"不可逆"确实能实现（A3 = 0.022–0.034），但实现它的是训练动力学，
不是新原理。** 判据与四次失败的改造尝试见 `docs/11`。

**v4.1 的降级理由是错的，已作废**

v4.1 写"T6 显示固定 η + gate 单独就够，故降级"。那个结论来自一个代码 bug：
`use_layer = mode in ("full", "no_gate", "frozen_eta")` 把 `frozen_eta`
也放进了分层分支，所以"η 恒定 + gate"实际上**仍在做硬冻结**。
修正后 E3c 在 6 类环境里 5 类出现分离（soft_only 0.40–1.00 vs full 0.0005–0.06）。
**"棘轮冗余"这个结论不成立，v4.1 的降级理由作废。**

**v4.2 的降级理由：装置本身是坏的，前三版测的都不是学习**

这一轮复查发现一个更根本的问题。v1/v2/v3 的学习规则是

```
err = w·dx,  Δw = η·err·x/|x|²
```

这是**抗赫布去相关**规则（让 `w·dx → 0`），不是预测规则。而 `dx` 张满 `R^d`，
`(A-I)` 可逆（实测最小奇异值 0.2601，零空间只有 0），所以**唯一不动点是 `w = 0`**：

```
旧规则 20000 步后 ||w|| = 2.434e-28   （初始 1.728）
```

**v1/v2/v3 测到的全部"印记"，都是权重向零崩塌途中的残留量。**
"晚/早 = 0.0033"不是"不可逆"，是"两次都没学到东西，比值由噪声决定"。

v4.2 换预测规则（`err_i = x_next[i] - w_i·x`，不动点 `w_i = A[i]`）后，
装置才第一次有效：预测 MSE 0.00252 vs 噪声地板 0.00250，`||W-A||/||A|| = 14.5%`。

**在有效装置上重测，A3 与 A5 从未同时成立**（`experiments/e3d_emergence.py`，
3 seeds，判据 A3: 晚/早<0.20；A5: 外围层对 B 的印记>0.15）：

```
机制              参数              认同层晚/早   外围B印记   A3     A5
hard（硬锁）       默认                 0.0057     0.0834    True   False
soft              beta=8 k=1e-3        1.0159    -0.1352    False  False
soft              beta=4 k=1e-2        1.4991    -0.0463    False  False
soft              beta=2 k=3e-2        0.4013    -0.0737    False  False
soft              beta=1 k=1e-1        0.8568    -0.0613    False  False
```

> **⚠️ 这张表在第五轮被证明测错了。** 早期窗口后还有 25,700 步可恢复，
> 晚期窗口只剩 800 步——"晚/早"比值测的是恢复速度，不是不可逆性。
> 那个 0.0057 无意义。修正后的表见下面"第五轮"一节。

两条结论：

1. **A3 只在硬锁下成立，而硬锁是构造，不是涌现。** 软阻抗在全部四组参数下
   晚/早都在 0.40–1.50，即"晚期照样能写进去"。所谓"不可逆"是 `if frozen: η=0`
   这一行代码给的，不是机制给的。
2. **A3 与 A5 从未并存。** 硬锁把 4/6 细胞彻底冻死，外围 2 个细胞学 B 只到 0.0834。
   "两周期命题"的两个必要条件，在同一个装置里互相排斥。

**所以 ③ 目前既没有可信的机制主张，也没有可信的验收数据。**
它不是 `INNOVATIVE`，也不是"降级到 PENDING 等一个实验"，而是**需要重新设计**：
"不可逆"到底该由什么物理量产生，目前方案里没有答案。

**v4.2 的降级理由（第四轮追加）：信噪比修好了**

上面那张表还有一个隐患：**它是在没有信噪比的情况下测的**（§10.6）。
把 `d` 从 24 降到 12、`amp` 提到 2.5、`gamma` 提到 2.0 后，S/N 从 0.50 升到
**1.70**，指标第一次能分辨养育信号。理想 MLE 的印记达 **+0.78 ~ +0.85**，
说明**实验设计本身没有问题**。这一条是第四轮唯一的正面成果，保留。

**v4.2 的降级理由（第五轮，取代第四轮的"时间尺度冲突"）**

第四轮接着写了一个结论——"闭锁 529–1943 步 vs 学习 30k–100k 步，差 20–100 倍"。
**那个结论是错的，已撤回。** 我把 LMS 的**稳态误调地板**读成了"学习很慢"：

```
η 恒定 0.30（mode=none）：500→30000 步，‖W−A‖/‖A‖ 始终 0.386–0.453
                                  ← 加 60 倍步数不下降，是 η·tr(R)/2，与步数无关
η 衰减（mode=eta_only）：  500 步 0.205 → 2000 步 0.111 → 30000 步 0.077
```

**2000 步就够了。** 20–100 倍的冲突不存在。

同一轮还发现 A3 的**旧测量设计本身有混淆**：早期窗口 `(300,4300)` 关闭后
还有 25,700 步可以恢复，晚期窗口 `(TT-4800,TT-800)` 关闭后只剩 800 步。
剂量相同、巩固时间差 24,900 步，所以"晚/早"比值测的是**恢复速度**。
那个 `0.0057` 不证明任何事。

改用等剂量 4000 + 等巩固 6000、只改窗口年龄后（`experiments/e3e_redesign.py`）：

```
mode      D_lock   效应早   效应晚   晚/早    A3
full       0.25    0.482   0.0089  +0.022   是
full       0.40    0.398   0.0149  +0.034   是
eta_only   0.25    0.072   0.0509  +0.644   否   ← 只 η 衰减，不闭锁
soft       0.25    0.483   0.0748  +0.149   是
```

两条新事实：

1. **A3 可以成立**，且与判据 0.20 差一个量级，不是勉强通过。
2. **`eta_only` 给不出 A3**（0.644）。所以 A3 确实需要"窗口关闭"——
   不是 `if frozen: eta=0` 那一行，而是**一定数量的细胞在窗口关闭前停止更新**。

而 A5 的失败被隔离干净了（`D_lock=0` 时无细胞闭锁，保留全部 η 衰减）：

```
D_lock=0.00  闭锁 0/12   A5 印记 +0.278   67% 细胞更接近 A+S
D_lock=0.10  闭锁 5/12   A5 印记 +0.093   25%
D_lock=0.15  闭锁 7/12   A5 印记 -0.019   17%
```

**闭锁数越多，A5 单调塌陷。A5 的失败是闭锁直接造成的。**

**"并存"是边界抖动伪造的。** 细扫时 `D_lock=0.075` 出现
A3=0.055（过）、A5=0.155（刚好过），像找到共存点。10 seeds 展开后：

```
A3 通过率 60%，A5 通过率 70%，同一 seed 上同时通过 3/10（n=10 时 1/5）
```

两个指标各自都能过，**但不在同一次运行里一起过**。这是两个边界抖动的联合
概率，不是机制。第四轮我拿不同参数下的两个最好值拼出一张表，看上去像
"并存"，实际没有一次运行同时满足。

> **写死的判据：A3 与 A5 必须在同一 seed 上同时成立，且跨 seed 稳定。**

**所以 ③ 的当前状态**：A3 有可复现路径，A5 被同一机制削弱，二者不可靠并存。
不是"设计失败"，也不是"待验证"，而是**必须换机制**：
让"闭锁"与"可学习"作用在**不同的物理量**上，而不是在同一批参数上争夺 η。

**唯一还没试的方向**：如果"不可逆"不来自参数冻结，而来自**结构**（哪些细胞
存在、如何连接），那么 A3 与 A5 就不必争夺同一批参数的可塑性——结构冻结
不阻止剩余通路继续学习。但这需要 ④ 发育环先有代码（§11 已把 E4 提到 ③ 的
前置位置），目前没有。在此之前，③ 保持 `PENDING`，且不得引用 v1–v3 的任何数字。

## 10. E3 实测结果（v4.2 复查，2026-11-27）

> **v1 与 v2 的结论全部作废，原因不是参数没调好，是学习规则本身是坏的。**
> 详见 §10.0。本节的数字来自新装置，且**多数结论是否定的**。

### 10.0 前三版为什么全部无效

v1/v2（以及初次重做的 v3）的学习规则是：

```
err = w·dx,   Δw = η·err·x/|x|²
```

这是抗赫布去相关（让 `w·dx → 0`），不是预测。而 `dx` 张满 `R^d`，
且 `(A−I)` 可逆（实测最小奇异值 **0.2601**，零空间只有 0），
所以**唯一不动点是 `w = 0`**：

```
旧规则 20000 步后 ||w|| = 2.434e-28      （初始 1.728）
权重相对移动 = 100.00%，M(w) 从 0.1405 → 0.0000（−100%）
```

**v1/v2 测到的每一个"印记"，都是权重向零崩塌途中的残留量。**
"晚/早 = 0.0033"不是不可逆，是"两次都没学到东西，比值由噪声决定"。
"保留 1.013"同理，已实测 `(A→无)/A = 1.000`（5/5 seeds），
即"换养育 B"与"什么都不做"完全等效——因为所有细胞都已闭锁，B 根本进不来。

### 10.1 新装置：预测式 LMS

改为 `err_i = x_next[i] − w_i·x`，不动点 `w_i = A[i]`（环境动力学的第 i 行）。
这才是"学会世界"，也才使"养育写进权重"有处可写。

| 指标 | 旧规则 | 新规则 | 判据 |
|---|---|---|---|
| `‖w‖` | 2.4e-28（塌向零） | 3.647（有界） | 不得塌 |
| `‖W−A‖/‖A‖` | 无意义 | **14.5%** | <20% |
| 预测 MSE | 无意义 | **0.00252** | 噪声地板 0.00250 |

指标也换：v2 用 `mean|w·u|`，无上界、跨条件不可比、且 `w→0` 时天然趋零。
改为有界指数 `imprint = (d0−d1)/(d0+d1)`，`d0=‖w−A[i]‖`、`d1=‖w−(A+S)[i]‖`，
取 `[−1,1]`，有端点含义（+1 完全吸收养育，−1 完全拒绝）。

### 10.2 在有效装置上重测：A3 与 A5 从未并存

判据在跑之前写死：A3 = 认同层晚/早 < 0.20；A5 = 外围层对 B 的印记 > 0.15。
`experiments/e3d_emergence.py`，3 seeds：

| 机制 | 参数 | 认同层晚/早 | 外围B印记 | A3 | A5 |
|---|---|---|---|---|---|
| hard（硬锁） | 默认 | **0.0057** | 0.0834 | ✅ | ❌ |
| soft | beta=8 k=1e-3 | 1.0159 | −0.1352 | ❌ | ❌ |
| soft | beta=4 k=1e-2 | 1.4991 | −0.0463 | ❌ | ❌ |
| soft | beta=2 k=3e-2 | 0.4013 | −0.0737 | ❌ | ❌ |
| soft | beta=1 k=1e-1 | 0.8568 | −0.0613 | ❌ | ❌ |

1. **A3 只在硬锁下成立，而硬锁是构造。** 软阻抗在四组参数下晚/早都在 0.40–1.50。
   "不可逆"是 `if frozen: eta=0` 这一行给的，不是机制给的。
2. **A3 与 A5 从未同时成立。** 硬锁冻死 4/6 细胞，外围 2 个学 B 只到 0.0834。

### 10.3 被证伪的假设（本轮）

| 我原先的判断 | 实测 | 修正 |

### 10.4 C3_slow_env 的整类失效（静默退化的标本）

`make_shift` 在 `spec(a_mat) ≥ max_radius` 时，二分搜索连 `mid=0` 都判超限，
`lo` 停在 0，函数**静默返回零矩阵**：

```
radius=0.85  ||shift||=1.200000  spec(a+shift)=0.8370   ← 正常
radius=0.90  ||shift||=1.152191  spec(a+shift)=0.8800   ← 收缩后可行
radius=0.95  ||shift||=0.000000  ← 零矩阵，静默坍缩
```

于是"养育窗口"与"无养育窗口"跑同一个环境，`de` 精确为 0，实验报 nan，
调用方看不出任何异常。**修法：不可行时抛 `ValueError`。**
静默退化比崩溃危险：崩溃会停下来，退化会把"没做实验"写成"实验失败"。

### 10.5 仍然成立的调试教训

| # | 教训 | 证据 |
|---|---|---|
| 1 | 任何 `f(当前状态)` 都不能做棘轮驱动量 | `Σ&#124;w·x&#124;` 饱和 14.21；`Σ&#124;Δw&#124;²` 速率比 0.000；只有 `Σ&#124;Δx&#124;` 达 0.958 |
| 2 | 全局标量驱动逐细胞参数 = 没有分层 | `load` 是标量 → `eta_eff` 数组每元素相同 → 外围层 η 也是 1.01e-4 |

第 6 条是本轮新发现：正确判据是**同一机制下的绝对值 + 噪声地板参照**
（`full` 晚期效应仅为噪声的 5.9 倍 = 不可测；`soft_only` 为 6552 倍 = 可测）。

### 10.6 第三次否决：指标没有信噪比 → 已解决

修完装置（预测式 LMS）、修完分层（认同层=先闭锁的那批，在线确定）之后，
结果仍然全是否定的，而这次否定的对象是**实验设计本身**。

指标用完美值校准是对的（`w=A` 给 −1，`w=A+S` 给 +1），但实际学到的权重下：

```
w 与 A 的距离（噪声底）: [0.243 0.352 0.255 0.301 0.326 0.106]
||S_i||（要测的信号）:   [0.073 0.028 0.194 0.245 0.045 0.203]
```

**噪声底大于信号。** 后果是两个方向都被压成负值：

```
只学 A -> 对 A 的印记 = -0.0845
只学 B -> 对 B 的印记 = -0.0685
```

**"只学 A"对 A 的印记是负的。** 即使给系统完美单一的养育，指标也测不出来。

**这一条已在第四轮修掉**（`docs/10` §9.8）：`d=24 → 12`、`amp=2.5`、`gamma=2.0`，
S/N 从 **0.50** 提到 **1.70**。修好之后理想 MLE 的印记达 **+0.78 ~ +0.85**，
"只学 A 对 A"的印记转正。所以 §10.2 的表**不是**实验设计问题造成的。

### 10.7 第四次否决（被第五轮推翻）：所谓"20–100 倍时间尺度冲突"

信噪比修好后，同一个问题换了个面孔回来。`D_lock` 全区间扫描：

| 0.05 | 1943 | 0.4236 | −0.5653 |
| 0.10 | 1283 | 0.3556 | −0.3145 |
| 0.15 | 1092 | 0.2799 | −0.0310 |
| 0.25 | 792 | 0.2885 | **+0.0260** |
| 0.40 | 529 | 0.3735 | −0.1263 |
| **理想 MLE** | — | **0.013–0.025** | **+0.78 ~ +0.85** |

我据此写了"在线 LMS 需要 30k–100k 步，闭锁只需 529–1943 步，差 20–100 倍"。
**那个 30k–100k 是错的**：它是 LMS 的稳态误调地板，不是收敛时间。

### 10.8 第五轮：把误调地板读成了收敛时间

实测（`experiments/e3e_redesign.py`，无养育、目标 A）：

```
步数            500    1000    2000    4000    8000   14000   30000
η 恒定 0.30   0.416  0.403   0.434   0.390   0.401   0.386   0.420   ← 不下降
η 衰减        0.205  0.141   0.111   0.099   0.117   —       0.077   ← 2000 步就够
```

**恒定 η 的 LMS 永不收敛到 A**，它停在 `η·tr(R)/2` 的误调水平，
加 60 倍步数也不降。我看到的"30k 步后还有 0.40"就是这个地板，
不是"还没学完"。

同一轮还发现 **A3 的旧测量设计混淆了剂量与巩固时间**：早期窗口
`(300,4300)` 关闭后还有 25,700 步可恢复，晚期窗口 `(TT-4800,TT-800)`
关闭后只剩 800 步。剂量相同、巩固时间差 24,900 步，所以"晚/早"比值
测的是**恢复速度**。那个 `0.0057` 不证明任何事。

修正为等剂量 4000 + 等巩固 6000、只改窗口年龄（早期 300 / 晚期 20000）：

| mode | D_lock | 效应早 | 效应晚 | 晚/早 | A3 |
|---|---|---|---|---|---|
| full | 0.25 | 0.482 | 0.0089 | **+0.022** | ✅ |
| full | 0.40 | 0.398 | 0.0149 | **+0.034** | ✅ |
| eta_only | 0.25 | 0.072 | 0.0509 | +0.644 | ❌ |
| soft | 0.25 | 0.483 | 0.0748 | +0.149 | ✅ |

**A3 第一次真正成立**，且与判据 0.20 差一个量级。而 `eta_only`（不闭锁）
给不出 A3，说明 A3 确实需要"窗口关闭"——不是 `if frozen: eta=0` 那一行，
而是**一定数量的细胞在窗口关闭前停止更新**。

A5 的失败也隔离干净了：`D_lock=0`（无闭锁）时 A5 印记 **+0.278**、
67% 细胞更接近 A+S；5/12 闭锁降到 +0.093；7/12 降到 −0.019。
**闭锁数越多，A5 单调塌陷。**

**但"并存"是边界抖动伪造的。** `D_lock=0.075` 时 A3=0.055、A5=0.155，
两个都"刚好过"。10 seeds 展开：

```
A3 通过率 60%，A5 通过率 70%，同一 seed 上同时通过 3/10（n=10 时 1/5）
```

两个指标各自都能过，**但不在同一次运行里一起过**。这是两个独立边界抖动的
联合概率，不是机制。第四轮我拿不同参数下的两个最好值拼出一张表，
看上去像"并存"，实际没有一次运行同时满足。

已写成测试（28 项不变量）：
`test_signal_exceeds_noise_floor`（信号必须大于噪声底）、
`test_constant_eta_never_converges`（恒定 η 不得因加步数而改善）、
`test_eta_decay_converges_fast`（η 衰减必须 2000 步内到 0.20 以下）、
`test_imprint_zero_point_is_indifference`（`w=0` 时印记≈0、`w=A` 时=−1）、
`test_a3_and_a5_measured_on_disjoint_cells`（两者必须测不同细胞）、
`test_a3_windows_have_equal_consolidation`（剂量与巩固时间必须相等）、
`test_online_lms_far_from_ideal`（在线与理想解仍差 3 倍以上）。
